Pick a provider by name, or let `auto` pick for you. A provider serves only the methods marked for it; ask a method for another's provider and it says so, naming the ones it does serve.

Your queries go to the provider you select, and each provider's terms govern your use of its
results. WebRouter does not change them. Provider names and logos are trademarks of their owners,
used here for identification only.

## Working with no credentials

You can start with no API keys. `auto`, the default for every method, uses the providers you have a key for first, and falls back to free tiers when you have none.

| Method | Free tiers, tried in this order |
| --- | --- |
| Search | Tavily, then You.com, Exa and Parallel (their open MCP servers), then Keenable |
| Extract | Tavily, then Jina Reader, Firecrawl, then Keenable |
| Browser session | `local` (a Chromium on your machine) |
| Answer, research, browse | None: every call is billed, so they need a key |

- **Rate limits.** Free tiers are rate-limited. When one is throttled, the next in the list answers.
- **Which one answered.** `response.provider` names the provider that served the call, never `"auto"`.
- **Missing key.** A method with no free tier raises an error that names the key to set.
