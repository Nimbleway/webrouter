## Setup

| Variable | | What it is |
|---|---|---|
| `GRAPHHOPPER_API_KEY` | required | a GraphHopper API key (graphhopper.com dashboard &gt; API keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billed in credits against a daily limit. Each response's X-RateLimit-Credits header gives the cost of that call and X-RateLimit-Remaining the credits left before it; 429 means the daily or per-minute limit is spent.
- Points are 'latitude,longitude' in requests, and multi-value parameters repeat (point=..&point=..); pass a list.
- The free package supports only the car, bike and foot profiles.
