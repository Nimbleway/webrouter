## Notes

- Keyless and free.
- Dataset names in the path and field names in &#36;select/&#36;filter are case-sensitive; the filter parser is strict about spaces, quotes and case.
- Each dataset is versioned in the path (v1, v2, ...); a newer version can replace an older one, so check datasets.list.
- Paging: &#36;top (default 1000, max 10000) with &#36;skip; set &#36;count=true to get the total in metadata (otherwise it reads 0).
