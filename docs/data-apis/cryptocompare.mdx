## Setup

| Variable | | What it is |
|---|---|---|
| `CRYPTOCOMPARE_API_KEY` | some calls | A CoinDesk Data (formerly CryptoCompare) API key from developers.coindesk.com. Sent as the api_key query parameter; some endpoints work without one. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- This is the Data API (data-api.cryptocompare.com, also served at data-api.coindesk.com); the older min-api endpoints are not in this entry.
- Pairs are written BASE-QUOTE (BTC-USD). Index endpoints take an index family as market (cadli by default); spot endpoints take an exchange.
- List-valued inputs (instruments, assets, groups, categories) are comma-separated strings.
- Rate limits apply per second, minute, hour, day and month; going over returns 429.
