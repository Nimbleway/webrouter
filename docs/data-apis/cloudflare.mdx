## Setup

| Variable | | What it is |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | required | a Cloudflare API token (My Profile &gt; API Tokens) with Zone Read, Analytics Read and DNS Read as needed |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- REST answers are wrapped as &#123;success, errors, messages, result, result_info&#125;; page with page and per_page and read result_info.total_pages.
- Analytics are GraphQL only: POST a query against viewer.zones(filter: &#123;zoneTag&#125;) or viewer.accounts(filter: &#123;accountTag&#125;) and a dataset node such as httpRequestsAdaptiveGroups or firewallEventsAdaptive. Zone ids come from cloudflare.zones.list.
- GraphQL quota: 300 queries per 5 minutes per user by default; up to 10 zones or 1 account per query. Adaptive datasets keep at least 31 days on every plan; aggregated ones (httpRequests1hGroups, 1dGroups) have per-plan lookback limits.
- Cloudflare also accepts the legacy global API key (X-Auth-Email + X-Auth-Key); this entry uses an API token.
