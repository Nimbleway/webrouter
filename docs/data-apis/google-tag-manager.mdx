## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_TAG_MANAGER_CLIENT_ID` | required | the OAuth client id of a Google Cloud OAuth app with the Tag Manager API enabled (Google Cloud console &gt; APIs & Services &gt; Credentials) |
| `GOOGLE_TAG_MANAGER_CLIENT_SECRET` | required | that OAuth app's client secret |
| `GOOGLE_TAG_MANAGER_REFRESH_TOKEN` | required | a refresh token minted with that OAuth app for the scope https://www.googleapis.com/auth/tagmanager.readonly (reads), tagmanager.edit.containerversions and tagmanager.publish (the write calls) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: every call acts as the Google user the refresh token belongs to, and only reaches accounts that user can access.
- Resources nest: account &gt; container &gt; workspace &gt; tags, triggers, variables. Ids are digits; the public GTM-XXXX id is not an API id.
- Lists page with pageToken/nextPageToken. A publish makes a container version live on the real site; create_version only snapshots a workspace.
- Per-method OAuth scopes are narrower than one broad token: reads need tagmanager.readonly, creating a version needs tagmanager.edit.containerversions, publishing needs tagmanager.publish.
