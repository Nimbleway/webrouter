## Setup

| Variable | | What it is |
|---|---|---|
| `SUPADATA_API_KEY` | required | a Supadata API key (dash.supadata.ai &gt; API key). Sent in the x-api-key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billed in credits; every response carries an x-billable-requests header with the credits it used (on a 202 job answer it is a precharge estimate, reconciled when the job finishes). Polling a job is free.
- Transcript, extract and crawl can answer 202 with a jobId instead of a result: poll the matching job endpoint until it is done.
- Transcript chunks give offset and duration in milliseconds.
- Crawl, YouTube batch jobs, playlist and channel metadata and transcript translation are in the API but not in this entry.
