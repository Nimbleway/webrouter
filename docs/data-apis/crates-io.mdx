## Setup

| Variable | | What it is |
|---|---|---|
| `CRATES_IO_USER_AGENT` | optional | The User-Agent crates.io requires, identifying your application; it asks for a way to contact you, e.g. 'my-tool (https://github.com/me/my-tool)'. Default `web-router`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keyless. The data-access policy allows at most 1 request per second and a User-Agent naming your application; for bulk work it points to the sparse index, the database dump or the RSS feeds instead.
- The OpenAPI description is marked experimental and the API may change.
- Paging uses page or seek (from meta.next_page), never both.
