## Setup

| Variable | | What it is |
|---|---|---|
| `OPENCAGE_API_KEY` | required | An OpenCage API key (opencagedata.com &gt; Dashboard), sent as the key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- One path does both directions: q is an address or place for forward geocoding, or 'latitude,longitude' (latitude first, decimal point) for reverse.
- Free trial: 2,500 requests per day (reset at 00:00 UTC; 402 when spent) and 1 request per second (429 when exceeded). The free trial is for testing, not production.
- no_annotations=1 makes answers smaller and faster when timezone, currency and the other annotations are not needed.
