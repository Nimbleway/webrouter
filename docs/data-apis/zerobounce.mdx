## Setup

| Variable | | What it is |
|---|---|---|
| `ZEROBOUNCE_API_KEY` | required | a ZeroBounce API key (API page of your ZeroBounce account) |
| `ZEROBOUNCE_API_HOST` | optional | API host: the default, the U.S.-only host (api-us) or the EU host (api-eu). Default `api.zerobounce.net`. One of `api.zerobounce.net`, `api-us.zerobounce.net`, `api-eu.zerobounce.net`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The API key travels as the api_key query parameter on every call.
- A credit is used per validated email, never for an 'unknown' result. Test without credits using the sandbox addresses in the Sandbox Mode docs.
- Rate limit on validate: 80,000 requests per 10 seconds (100,000 for ZeroBounce ONE).
- Bulk file validation (sendfile, filestatus, getfile, deletefile) lives on a different host, bulkapi.zerobounce.net, and the batch endpoint takes api_key in its JSON body; neither is in this entry.
