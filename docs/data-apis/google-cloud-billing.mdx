## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_CLOUD_BILLING_API_KEY` | required | a Google Cloud API key from a project with the Cloud Billing API enabled |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Covers the public SKUs and their list prices.
- A price is units plus nanos (billionths): &#36;1.75 is units=1, nanos=750000000. pricingInfo is a chronological timeline of pricingExpression entries.
- Pages hold up to 5,000 items; send nextPageToken back as pageToken until none is returned.
- Prices are in USD unless currencyCode is set; currencyConversionRate in each pricingInfo is the rate from USD that was applied.
