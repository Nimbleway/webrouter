## Setup

| Variable | | What it is |
|---|---|---|
| `TAKO_API_KEY` | required | A Tako API key (tako.com/console/api-keys). Sent in the X-API-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Prepaid credits; calls return HTTP 402 when the balance runs out. Data graph calls cost &#36;1 per 1,000 requests (docs overview).
- Typical data flow: graph.search to resolve an entity or metric id, graph.related to find its metrics, then search or contents for the data.
- Monitors and notification channels are experimental and not in this entry.
