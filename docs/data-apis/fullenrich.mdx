## Setup

| Variable | | What it is |
|---|---|---|
| `FULLENRICH_API_KEY` | required | A FullEnrich API key (app.fullenrich.com/app/api). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- 60 API calls per minute across all endpoints; enrich and reverse lookup take up to 100 contacts per call, with 100 concurrent enrichments per workspace.
- Credits are spent only when something is found; see each endpoint's notes for the price.
- Enrichment data is kept 3 months (GDPR); fetch results within that window.
- Sub-account and bring-your-own-key management endpoints are not in this entry.
