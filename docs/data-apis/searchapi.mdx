## Setup

| Variable | | What it is |
|---|---|---|
| `SEARCHAPI_API_KEY` | required | a SearchApi API key (the dashboard at searchapi.io) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every engine is the same GET /api/v1/search with a different engine value; the engine's own parameters follow.
- The key goes in the Authorization header as a Bearer token; the docs also accept it as an api_key query parameter, which this file does not use.
- A bad key is HTTP 401 with &#123;"error": "Invalid API key."&#125; (called live on 2026-11-24).
- Only successful searches, those answered with HTTP 200, are billed (pricing page).
- Paging is by page number (1-based). Google phased out num in September 2025, so a Google web page holds at most 10 organic results and num is left out here; Bing pages with next_page_token.
- A Google result that is a redirect carries a link_token instead of a final URL; the Google Resolve API turns it into the destination.
- search_metadata.status is Success or Error, and search_metadata.json_url and html_url point at the stored copy of the response.
