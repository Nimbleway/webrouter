## Setup

| Variable | | What it is |
|---|---|---|
| `FIXER_API_KEY` | required | A Fixer API access key (fixer.io dashboard). Sent as the access_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The default base currency is EUR.
- Errors come back as JSON with success false and an error object (code, type, info); check success, not only the HTTP status.
- spread (bid and ask) needs the Professional plan or higher; a lower plan gets an upgrade message instead.
