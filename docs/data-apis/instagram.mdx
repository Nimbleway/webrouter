## Setup

| Variable | | What it is |
|---|---|---|
| `INSTAGRAM_ACCESS_TOKEN` | required | An access token for the Instagram professional account: a Facebook Login user or system-user token, or an Instagram Login token (Meta App Dashboard &gt; Instagram &gt; API setup) |
| `INSTAGRAM_GRAPH_HOST` | optional | graph.facebook.com for Facebook Login or a system-user token; graph.instagram.com for Instagram Login tokens. Default `graph.facebook.com`. One of `graph.facebook.com`, `graph.instagram.com`. |
| `META_GRAPH_API_VERSION` | optional | Graph API version. Meta retires old versions about two years after release. Default `v27.0`. One of `v27.0`, `v26.0`, `v25.0`, `v24.0`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Only for Instagram business or creator accounts connected to your Meta app, with the permissions each call lists in its docs. Tokens are tied to the app user.
- Publishing is two calls: media.create_container, then media.publish. Both change the account, so they are writes.
- Insights data can lag 48 hours; missing data comes back as an empty set, not 0.
- Paging uses cursors in paging.cursors.after; follow paging.next when present.
