## Notes

- Keyless.
- Search terms use ClinicalTrials.gov's Essie expression syntax (AND, OR, NOT, AREA[Field]value, quotes for phrases).
- Paging is by token: a response with nextPageToken has more; pass it as pageToken and repeat every other parameter unchanged (only countTotal, pageSize and pageToken may change). A page can come back with an empty studies list.
- A full study record is large: pass fields (comma- or pipe-separated piece names such as NCTId,BriefTitle,OverallStatus) to keep responses small. /studies/metadata lists the field names.
