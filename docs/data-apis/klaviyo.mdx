## Setup

| Variable | | What it is |
|---|---|---|
| `KLAVIYO_API_KEY` | required | a Klaviyo private API key (Settings &gt; API keys) with read scopes for campaigns, flows and metrics |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call carries a revision header (an API version date); this entry pins 2026-10-15.
- Bodies are JSON:API: &#123;"data": &#123;"type": ..., "attributes": &#123;...&#125;&#125;&#125;. List filters are strings such as equals(status,'live') or greater-than(created,2026-01-01T00:00:00Z); paging follows links.next or page[cursor].
- Reporting endpoints (campaign and flow values) are rate limited hard: 1 per second, 2 per minute, 225 per day. They match the numbers in Klaviyo's UI; metric aggregates are for raw event counts.
- Reports need a conversion_metric_id: find the Placed Order (or other conversion) metric's id with klaviyo.metrics.list.
