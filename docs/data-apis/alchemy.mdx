## Setup

| Variable | | What it is |
|---|---|---|
| `ALCHEMY_API_KEY` | required | An Alchemy API key (dashboard.alchemy.com). Sent as an Authorization Bearer header rather than in the URL. |
| `ALCHEMY_NETWORK` | optional | Network the token, transfer and NFT calls read, e.g. eth-mainnet, base-mainnet, polygon-mainnet. Default `eth-mainnet`. One of `eth-mainnet`, `eth-sepolia`, `base-mainnet`, `polygon-mainnet`, `arb-mainnet`, `opt-mainnet`, `bnb-mainnet`, `avax-mainnet`, `zksync-mainnet`, `linea-mainnet`, `worldchain-mainnet`, `scroll-mainnet`, `zora-mainnet`, `mantle-mainnet`, `unichain-mainnet`, `abstract-mainnet`, `ink-mainnet`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Usage is billed in compute units per call (listed per endpoint); throughput is capped per plan.
- Token, transfer and NFT calls go to the network set in ALCHEMY_NETWORK; not every API runs on every network.
- JSON-RPC calls (token and transfer) answer with result or error inside a 200; check error.
- The Prices API is not in this entry: it takes the key in the URL path (/prices/v1/&#123;apiKey&#125;/...), and this entry sends the key only in the Authorization header.
