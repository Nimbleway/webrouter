| `SIGNALHIRE_API_KEY` | required | A SignalHire API key (Other tools &gt; Integrations & API). Sent in the apikey header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billing is split: person lookups spend standard credits, without-contacts lookups and company profiles each spend their own credit type, and people search draws on a daily quota shared with the web app.
- The default person lookup and the company employee-profile export deliver only to a callback URL, so they are not in this entry; person lookup is listed in its synchronous mode.
- The Company API is off by default; SignalHire support enables it.
