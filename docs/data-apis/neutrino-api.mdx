## Setup

| Variable | | What it is |
|---|---|---|
| `NEUTRINO_USER_ID` | required | Your Neutrino API user ID (the fixed ID of your account). Sent in the User-ID header. |
| `NEUTRINO_API_KEY` | required | A Neutrino API key (generated in your Neutrino account). Sent in the API-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every API takes its parameters over GET or POST; this entry uses GET. Field names in responses are kebab-case by default (output-case can switch to camel or snake).
- Each API has its own rate and concurrency limits, listed per endpoint; past the concurrency limit the error code is 06 TOO MANY CONNECTIONS.
- SMS Verify, Phone Verify and Phone Playback send messages or calls and are not in this entry; nor are the browser, HTML render and imaging APIs.
