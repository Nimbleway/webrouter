## Setup

| Variable | | What it is |
|---|---|---|
| `OFAC_SLS_USER_AGENT` | optional | The User-Agent sent with every request; the SLS host rejects requests without one (403). E.g. your application name and a contact. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free and keyless, but the host answers 403 to requests with no User-Agent header; set OFAC_SLS_USER_AGENT.
- These are whole-list XML downloads, not a search API: download once and match locally, and re-download when OFAC publishes changes.
- The old www.treasury.gov/ofac/downloads/&lt;file&gt; URLs redirect here.
- The XML schemas are at /api/PublicationPreview/exports/XML.xsd (standard files) and /api/PublicationPreview/exports/ADVANCED_XML.xsd (advanced files).
