| Variable | | What it is |
|---|---|---|
| `SALESINTEL_API_KEY` | required | A SalesIntel API key, issued by your SalesIntel success team. Sent in the X-CB-ApiKey header. |

## Notes

- Credits follow the records returned, not the requests; 402 when the account lacks credits, 403 when it lacks permission for a service.
- 1,800 requests a minute per user; 429 beyond.
- Export apps, webhooks and the Snowflake share are not in this entry.
