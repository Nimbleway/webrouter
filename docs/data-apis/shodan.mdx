## Setup

| Variable | | What it is |
|---|---|---|
| `SHODAN_API_KEY` | required | A Shodan API key (account.shodan.io), sent as the key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Query credits come with the plan: filtered searches, pages past the first and DNS domain lookups spend them; api.info shows what is left.
- Search syntax is the website's: free text plus filter:value pairs (search.filters lists them).
- On-demand scans, network alerts, notifiers, bulk data and organization calls are not in this entry.
