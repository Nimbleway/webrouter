## Notes

- Keyless, free and best-effort. Data is CC-BY: cite the CIRCL hashlookup page.
- A match means the file is known (e.g. shipped by an OS or package), not that it is safe or malicious. hashlookup:trust runs 0 to 100: 50 is no opinion, higher means seen in more sources.
- Hashes are hex; the documented examples use upper case.
