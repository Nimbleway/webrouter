## Setup

| Variable | | What it is |
|---|---|---|
| `ABSTRACT_IP_INTELLIGENCE_API_KEY` | required | The API key of Abstract's IP Intelligence API (Abstract dashboard). Each Abstract API has its own key; an email or phone key will not work here. Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Only the IP Intelligence API is in this entry; Abstract's other APIs each need their own key.
- Free plans allow 1 request per second (429 past it) and answer 422 when the credits run out. A 204 means there is no location data for the IP.
