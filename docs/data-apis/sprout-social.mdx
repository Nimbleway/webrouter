## Setup

| Variable | | What it is |
|---|---|---|
| `SPROUT_SOCIAL_API_KEY` | required | A Sprout Social API token (Generate API Token in the API Token Management section of Sprout; the plan must include API access and the user needs the API Permissions permission). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call but sprout-social.metadata.client takes a customer_id in the path: read it from sprout-social.metadata.client first.
- Profile ids (customer_profile_id) come from sprout-social.metadata.profiles; analytics and messages filters need them.
- Rate limits: 60 requests a minute, refilled at one a second, and 250,000 a month; X-RateLimit-Limit and X-RateLimit-Remaining report where you stand; over the limit a call gets a 429.
- Filters are strings in Sprout's own syntax: field.op(values), e.g. customer_profile_id.eq(1234, 5678) or created_time.in(2024-04-01T00:00:00..2024-04-30T23:59:59); '..' includes the end, '...' excludes it.
- Publishing, media upload and case changes are writes and are not in this entry; listening topics and cases are not listed either.
