## Setup

| Variable | | What it is |
|---|---|---|
| `SPIDER_API_KEY` | required | a Spider API key (spider.cloud/api-keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Auth is 'Authorization: Bearer &lt;key&gt;'. Without a key only /scrape answers; every other route returns 402.
- Pricing is credits: &#36;1 buys 10,000 credits; bandwidth and compute time are billed separately.
- Spider also has /unlimited/* routes, /transform, /unblocker (deprecated) and /ai/* routes, not in this entry.
- Large crawls can return many pages; set limit and prefer return_format markdown.
