## Setup

| Variable | | What it is |
|---|---|---|
| `ATTIO_API_KEY` | required | an Attio access token generated in Workspace settings &gt; Developers, with the read scopes needed (record_permission:read, object_configuration:read, list_entry:read, list_configuration:read, note:read, task:read, user_management:read) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Records hold attribute values as arrays of value objects with history fields (active_from, active_until); read the current value from the active entry.
- Filters and sorts name attributes by slug; get them from attio.attributes.list.
- Rate limit: 100 read requests per second across the API, lower on some endpoints; 429 answers carry a Retry-After date.
- Paging is limit and offset.
