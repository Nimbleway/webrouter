## Setup

| Variable | | What it is |
|---|---|---|
| `CAPTAINDATA_API_KEY` | required | A Captain Data API key (app.captaindata.com/developers); each workspace user has their own. Sent in the X-API-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call spends credits (see each endpoint); the daily credit quota is separate from the rate limit.
- Rate limit by plan, from 1 request/second (Trial) to 40 (Titanium); a 429 means back off.
- Paging is by cursor: follow the X-Pagination-Next response header (or pass its cursor) until it is absent. Page numbers were removed on 2026-01-15.
- Search endpoints take a raw LinkedIn Sales Navigator query string, not keyword parameters.
