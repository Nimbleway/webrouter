## Setup

| Variable | | What it is |
|---|---|---|
| `DEBOUNCE_API_KEY` | required | A private DeBounce API key, 13 characters (app.debounce.io/api). Sent as the api query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- A private key allows 5 concurrent calls, or 2 when data enrichment (append) is on; past that the API answers 429.
- Every reply carries success as "1" or "0"; on failure the debounce object holds an error message (401 wrong key, 402 credits low).
- Values come back as strings ("true", "1", balance as a string), not booleans or numbers.
- Bulk list upload and its status are not in this entry: only one bulk job runs per account and results come back as a CSV download link.
