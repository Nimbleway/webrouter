|---|---|---|
| `AIARK_API_KEY` | required | an AI Ark API key from the API Management dashboard (https://app.ai-ark.com/settings/api-management/dashboard) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Search endpoints are POST with page (zero-based) and size (max 100) required in the body.
- Credit-based: people.search 0.5 per person, company.search 0.1 per company, preview 1 per page. Check account.credits before large jobs.
- Filters nest as &#123;field: &#123;any|all: &#123;include, exclude&#125;&#125;&#125;; text filters take a match mode (SMART or WORD) with content.
