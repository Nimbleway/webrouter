## Setup

| Variable | | What it is |
|---|---|---|
| `FANTASTICJOBS_API_KEY` | required | A Fantastic.jobs API key (dashboard.fantastic.jobs), sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Two meters: Jobs credits, one per job returned by active-ats and active-jb; and API Requests, one per call on every endpoint. Modified, expired and organization endpoints use no Jobs credits. x-api-jobs-* and x-api-requests-* headers show usage.
- Rate limit: 600 requests per minute.
- Built for polling into your own store: time_frame 1h or 24h on a schedule, expired-ats to drop stale rows. Jobs appear 1-2 hours after the source publishes them.
- Use a count endpoint to size a query before pulling it, since every returned job costs a credit.
- This is the data.fantastic.jobs v1 API; the older api.fantastic.jobs and marketplace listings use other parameter and field names.
