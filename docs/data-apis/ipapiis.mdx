## Setup

| Variable | | What it is |
|---|---|---|
| `IPAPI_IS_API_KEY` | some calls | an ipapi.is API key (free account: 1,000 requests a day). Optional for single IP lookups, required for ASN lookups and the account endpoint |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Without a key: 30 lookups per IP per UTC day, with a minimal response and no detection flags; the next requests get 429 ERR_FREE_TIER_EXHAUSTED, and persisting can get the IP firewalled for 24 hours.
- A free account key allows 1,000 requests a day; errors are not counted. 429 ERR_QUOTA_EXCEEDED means the daily quota is spent.
- Switch parameters (pretty, geoloc_meta, all_companies) take effect only with the exact value 1.
- Errors are JSON with error and error_code (e.g. 400 ERR_INVALID_IP_OR_ASN, 403 ERR_FORBIDDEN_API_KEY_REQUIRED).
