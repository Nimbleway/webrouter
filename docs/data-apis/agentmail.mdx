## Setup

| Variable | | What it is |
|---|---|---|
| `AGENTMAIL_API_KEY` | required | An AgentMail API key from the AgentMail console. Sent as a Bearer token. |
| `AGENTMAIL_API_HOST` | optional | API host: api.agentmail.to (default) or api.agentmail.eu for the EU region. Default `api.agentmail.to`. One of `api.agentmail.to`, `api.agentmail.eu`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every path is under /v0 and scoped to an inbox: messages and threads need the inbox_id returned by the inbox list.
- Lists page by token: pass next_page_token from a response back as page_token.
- Free plan: 3 inboxes and 100 emails a day. A 429 carries Retry-After.
