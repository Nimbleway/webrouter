## Setup

| Variable | | What it is |
|---|---|---|
| `CRUSTDATA_API_KEY` | required | a Crustdata API key from the dashboard (https://crustdata.com) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call carries the pinned x-api-version 2025-11-01 header (set by this catalog).
- Credit-based with per-endpoint rate limits (15 to 45 requests per minute by default). Some live Company and Person endpoints need an enterprise plan; account.credits shows the balance.
- Filters are JSON condition objects &#123;field, type, value&#125; using dot-path fields; discover valid values with company.autocomplete.
