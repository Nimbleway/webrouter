## Setup

| Variable | | What it is |
|---|---|---|
| `BUILTWITH_API_KEY` | required | A BuiltWith API key (builtwith.com &gt; API). Sent as 'Authorization: API &lt;key&gt;'; the KEY query parameter also works but leaks into logs. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credits: 1 per domain on Domain, Relationships (per domain across its pages for 10 minutes), Company to URL, Keywords, Redirects and Trust; Free, Trends, WhoAmI and Usage cost nothing. Lists needs a subscription. X-API-CREDITS-* response headers show the balance.
- Rate limit: 8 concurrent requests and 10 per second; over it returns 429.
- Paths carry the format: these entries use api.json. Well-formed errors come back in an Errors array; treat any non-200 as an error too.
- Technology names use dashes for spaces (AB-Tasty). Check a name for free with the Trends API before spending credits on Lists.
