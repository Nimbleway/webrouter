## Setup

| Variable | | What it is |
|---|---|---|
| `WHOISXML_API_KEY` | required | A WhoisXML API key (My products page). Sent as Authorization: Bearer, which the WHOIS API accepts. |
| `WHOISXML_API_KEY` | required | The same key, sent in the X-Authentication-Token header that WHOIS history and reverse WHOIS accept. |
| `WHOISXML_API_KEY` | required | The same key, sent as the apiKey query parameter: the only way the DNS, subdomains and balance docs give. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Two credit pools: WHOIS credits (WHOIS API) and Domain Research Suite credits (history, reverse WHOIS, subdomains and more). A free account gets 500 of each kind; account.balance shows what is left.
- Rate limits: the WHOIS API allows 200 requests per second; DNS, history, reverse WHOIS and subdomains 30. Over it is a 429 (Retry-After on the WHOIS API).
- A new key takes up to a minute to activate.
