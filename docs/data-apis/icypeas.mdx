## Setup

| Variable | | What it is |
|---|---|---|
| `ICYPEAS_API_KEY` | required | An Icypeas API key (Icypeas dashboard &gt; API). Sent as is in the Authorization header, no Bearer prefix. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call but the two scrape GETs is a POST.
- Single email and domain searches are asynchronous: they return an _id; read the result with results.read.
- Credits: email search 1 and domain search 1 when found, verification 0.1, lead database about 0.02 per result, profile or company scrape from 0.5.
- The multi-row url-search, scrape and reverse-lookup batch endpoints are not in this entry.
