|---|---|---|
| `RIDB_API_KEY` | required | your RIDB API key (ridb.recreation.gov), sent in the apikey header |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- List responses wrap records in RECDATA with paging in METADATA; page with limit (max 50) and offset.
- Rate limit: 50 requests per second.
