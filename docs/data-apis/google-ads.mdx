## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_ADS_DEVELOPER_TOKEN` | required | a Google Ads developer token (manager account &gt; Admin &gt; API Center) |
| `GOOGLE_ADS_CLIENT_ID` | required | the OAuth client id of a Google Cloud OAuth app with the Google Ads API enabled |
| `GOOGLE_ADS_CLIENT_SECRET` | required | that OAuth app's client secret |
| `GOOGLE_ADS_REFRESH_TOKEN` | required | a refresh token for the adwords scope, minted with that OAuth app |
| `GOOGLE_ADS_API_VERSION` | optional | Google retires each major version about a year after release (v26: Oct 2026, sunsets Nov 2027). A sunset version answers 400 UNSUPPORTED_VERSION; pin one only to stay on it deliberately. Default `v26`. One of `v26`, `v25`, `v24`, `v23`. |
| `GOOGLE_ADS_LOGIN_CUSTOMER_ID` | optional | The manager (MCC) account id, digits only, when your login reaches client accounts through a manager. Leave unset when you are a user of the client account itself. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Two credentials on every call: an OAuth access token for a user with access to the account, and the developer token of an approved manager account. A missing or unapproved developer token answers DEVELOPER_TOKEN_* errors, not 401.
- Google has no read-only Ads scope: the adwords scope can read and change everything the user can. The catalog lists only read endpoints; a mutate through vendor_request is still refused unless allow_writes is passed.
- Customer ids are digits only: strip the dashes the Ads UI shows (123-456-7890 -&gt; 1234567890).
- Money is in MICROS of the account currency: divide cost_micros by 1,000,000.
- A test developer token only reaches test accounts; Basic access caps daily operations (see pricing_url).
