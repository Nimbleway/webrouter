## Setup

| Variable | | What it is |
|---|---|---|
| `INTRINIO_API_KEY` | required | An Intrinio API key (account.intrinio.com). Sent as an Authorization Bearer header; an api_key query parameter also works. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Access is per data-feed subscription: an endpoint is usable only with a feed that covers it.
- Limits depend on the subscription: requests per day (reset at midnight Eastern), per minute and per second; over a limit returns 429 with the reason.
- Paged endpoints return 100 rows and a next_page token; pass it back until it is null. page_size above 100 is limited to 1 request a minute (free) or a second (paid).
