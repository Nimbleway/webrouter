## Setup

| Variable | | What it is |
|---|---|---|
| `SCREENSHOTONE_API_KEY` | required | A ScreenshotOne access key (dashboard &gt; Access). Sent as the access_key query parameter, the form every endpoint documents (take also accepts an X-Access-Key header). |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- A rendered screenshot counts against the plan's quota; results served from cache (cache=true) do not. GET /usage is free.
- The answer is the image or PDF bytes by default (Content-Type by format); set response_type=json for a JSON answer. Errors are JSON with an error code and message.
- Signed requests (a signature parameter) are optional unless signing enforcement is turned on for the key; this entry sends the key unsigned.
- omit_background works only with png; webp and jpeg refuse it even as false.
