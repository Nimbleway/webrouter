## Setup

| Variable | | What it is |
|---|---|---|
| `FACEBOOK_ACCESS_TOKEN` | required | A Page access token (or a system-user token) from your Meta app, with the Pages permissions the call needs (Meta for Developers &gt; your app &gt; Graph API Explorer) |
| `META_GRAPH_API_VERSION` | optional | Graph API version. Meta retires old versions about two years after release. Default `v25.0`. One of `v25.0`, `v26.0`, `v27.0`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Most Page calls need a Page access token, obtained by exchanging a user token; the Pages a user manages come from user.accounts.
- Reading Page content and publishing need Meta App Review for the pages_* permissions.
- Lists page with paging.cursors.after; follow paging.next when present.
- Rate limits are per Page: error 80001 means too many calls, wait and retry.
