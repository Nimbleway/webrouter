## Setup

| Variable | | What it is |
|---|---|---|
| `KEEPA_API_KEY` | required | A Keepa private API access key (keepa.com &gt; API). Sent as the key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billed in tokens from a per-minute refill. Every answer carries tokensLeft, refillIn (ms), refillRate (per minute) and tokensConsumed; when tokens run out the API answers 503 until they refill.
- Prices are integers in the locale's smallest unit (4900 = &#36;49.00; in Japan 4900 = 4900 yen); -1 means no offer at that time.
- Times in csv histories are Keepa minutes: unix_ms = (keepa_minute + 21564000) * 60000.
- domain is a number, not a hostname: 1 is amazon.com.
- Product finder, deals, lightning deals and product tracking (which writes) are not in this entry.
