## Setup

| Variable | | What it is |
|---|---|---|
| `AFFINITY_API_KEY` | required | an Affinity API key from Settings &gt; Manage Apps (needs the Generate an API key permission); it reads as its user |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call pins API version 2026-09-17 with the X-Affinity-Api-Version header.
- Field data comes back only for the fields named in fieldIds or fieldTypes; get the ids from the fields calls. Several values repeat the key (fieldIds=a&fieldIds=b).
- Paging is a cursor: follow pagination.nextUrl, or pass its cursor.
- Limits: 900 requests per user per minute; monthly calls by plan (Scale and Advanced 100k, Enterprise unlimited); 429 when hit. Calls to API v1 and v2 share the pool.
