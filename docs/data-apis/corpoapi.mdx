## Setup

| Variable | | What it is |
|---|---|---|
| `CORPOAPI_API_KEY` | required | a Corpo API key (ck_live_..., or ck_test_... which is never billed) from the dashboard at https://corpoapi.com/app |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Rate limit per key: free 5/s and 100/min, paying 50/s and 2,000/min; 429 carries Retry-After.
- List endpoints page by opaque cursor (limit 1-100, default 20): send pagination.next_cursor back as cursor with the same filters.
- Coverage differs by country: a 409 means the register does not publish that block. Check corpoapi.coverage.get.
- Failed responses are not billed.
