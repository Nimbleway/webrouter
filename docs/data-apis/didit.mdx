## Setup

| Variable | | What it is |
|---|---|---|
| `DIDIT_API_KEY` | required | A Didit application API key (console, or the programmatic sign-up); sk_live_ for live, sk_test_ for sandbox. Sent in the x-api-key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- A wrong or expired key answers 401; a missing key 403.
- Checks are billed per completed check from prepaid credit (full KYC &#36;0.33, AML screening &#36;0.20 at list price); the sandbox is free, with 500 test sessions per 24 hours per sandbox application.
- Session results arrive by webhook in production; list and decision calls are for lookups, not tight polling.
- Session decisions carry personal data (documents, faces, addresses): handle them as such.
