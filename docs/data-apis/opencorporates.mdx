## Setup

| Variable | | What it is |
|---|---|---|
| `OPENCORPORATES_API_KEY` | required | An OpenCorporates API token (opencorporates.com &gt; API account). Sent as the api_token query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- A key is required on every call; daily and monthly call quotas depend on the plan. Daily usage resets at midnight UTC; check it with opencorporates.account.status.
- Lists page with page and per_page: 30 per page by default, up to 100, and page stops at 100.
- Date filters take one date or a range start:end with either end open (2020-01-01: or :2020-12-31). Term filters take one term, a comma list (match all) or a pipe list (match any).
- Data is under the Open Database Licence (share-alike, attribution): link each company's opencorporates_url when you show it. A company temporarily redacted answers 503.
