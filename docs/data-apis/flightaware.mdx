Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call is billed: each endpoint has a fee per result set (15 records), and a call that returns several pages pays for each page, up to max_pages. Fees run from &#36;0.002 (airport weather) to &#36;0.05 (flight search) per set and more for history; the Personal tier includes &#36;5 of free usage a month.
- Rate limits by tier: Personal 10 result sets a minute, Standard 5 a second, Premium 100 a second.
- Prefer ICAO codes (KJFK, UAL, UAL1234) over IATA to avoid ambiguous matches.
- Paging: links.next is a link to the next set of records; pass its cursor value back as cursor.
- Alerts, flight intents, maps, Foresight and history endpoints are not in this entry.
