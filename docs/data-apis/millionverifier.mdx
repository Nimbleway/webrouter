## Setup

| Variable | | What it is |
|---|---|---|
| `MILLIONVERIFIER_API_KEY` | required | a MillionVerifier API key (API page of your MillionVerifier dashboard) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The key goes in the api query parameter. The docs publish a test key, API_KEY_FOR_TEST, that returns random results.
- The bulk file API (upload, fileinfo, filelist, download, stop, delete) is on another host, bulkapi.millionverifier.com, and takes the key as 'key'; it is not in this entry.
- Failures such as a bad key or missing email still come back with HTTP 200 and a message in the error field.
