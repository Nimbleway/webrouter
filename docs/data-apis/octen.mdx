## Setup

| Variable | | What it is |
|---|---|---|
| `OCTEN_API_KEY` | required | an Octen API key (octen.ai/platform/api-keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Auth is 'Authorization: Bearer &lt;key&gt;'; the x-api-key header also works. The API needs a payment method on the account.
- Rate limits are QPS per plan.
- Octen also offers image and video search, answer, agent, deep research, embeddings and generation endpoints, not in this entry.
- Web search (POST /search) is served by search(provider="octen"), so it is not listed here.
