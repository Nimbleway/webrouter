## Setup

| Variable | | What it is |
|---|---|---|
| `ETHERSCAN_API_KEY` | required | An Etherscan API key (etherscan.io &gt; API Keys). Sent as the apikey query parameter; one key covers every supported chain. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call is GET /v2/api with chainid, module and action; each endpoint here fixes module and action, and chainid picks the chain.
- Free plan: 3 calls/second and 100,000 calls/day on the free-tier chains only (Base, BNB Chain, OP, Avalanche and others need a paid plan). Calls past the daily cap are blocked until it resets.
- Endpoints marked PRO need the Standard plan or above.
- status '0' means an error or simply no records; read message and result.
- Amounts are integer strings in the smallest unit: wei for native balances, 10^decimals for tokens.
