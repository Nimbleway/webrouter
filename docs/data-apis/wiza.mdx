## Setup

| Variable | | What it is |
|---|---|---|
| `WIZA_API_KEY` | required | A Wiza API key (Wiza account &gt; API; see the Generate an API Key page). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Reveals are asynchronous: start, then poll the get endpoint.
- Credits are prepaid and deducted only when data comes back.
- The legacy list endpoints (create list, get list contacts, prospect lists) and the location and technology autocomplete lookups are not in this entry.
