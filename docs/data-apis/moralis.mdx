## Setup

| Variable | | What it is |
|---|---|---|
| `MORALIS_API_KEY` | required | A Moralis API key (admin.moralis.com). Sent in the X-API-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- No self-serve free plan; paid plans include a monthly compute-unit (CU) allowance, and each endpoint costs a set number of CUs (info.endpoint_weights lists them). Multi-chain calls cost per chain.
- Rate limits are requests per second per plan (40 on Starter), measured over a rolling 4-second window; over it returns 429.
- chain takes a name (eth, base, polygon, bsc, arbitrum, optimism, avalanche, linea...) or hex chain ID; default eth.
- List endpoints page with cursor: pass the cursor from the previous response while one is returned.
