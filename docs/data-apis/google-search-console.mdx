## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_SEARCH_CONSOLE_CLIENT_ID` | required | the OAuth client id of a Google Cloud OAuth app with the Search Console API enabled (Google Cloud console &gt; APIs & Services &gt; Credentials) |
| `GOOGLE_SEARCH_CONSOLE_CLIENT_SECRET` | required | that OAuth app's client secret |
| `GOOGLE_SEARCH_CONSOLE_REFRESH_TOKEN` | required | a refresh token minted with that OAuth app for the scope https://www.googleapis.com/auth/webmasters.readonly (reads) or https://www.googleapis.com/auth/webmasters (to submit sitemaps) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: only properties the signed-in Google user has in Search Console.
- The siteUrl path segment must be percent-encoded ('sc-domain%3Aexample.com', 'https%3A%2F%2Fwww.example.com%2F').
- Dates are Pacific Time. Results come back sorted by clicks, or by date when grouped by date; the API returns top rows, not every row.
- Search analytics pages with startRow; at most 25,000 rows per call.
