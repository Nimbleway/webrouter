## Setup

| Variable | | What it is |
|---|---|---|
| `FIRECRAWL_API_KEY` | required | a Firecrawl API key, starting fc- (firecrawl.dev/app &gt; API Keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Auth is 'Authorization: Bearer &lt;key&gt;'. All paths are under /v2.
- Crawl and extract are asynchronous: start returns an id, then poll the matching status endpoint; finished results are paged with a 'next' URL.
- Timeouts are in milliseconds.
- Scraping one page or a list of pages goes through web-router's extract (it fans a list out over Firecrawl's scrape), not this entry.
