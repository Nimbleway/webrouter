## Setup

| Variable | | What it is |
|---|---|---|
| `NCBI_API_KEY` | some calls | Optional NCBI API key (NCBI account &gt; Settings &gt; API Key Management); sent as the api_key query parameter, raising the limit from 3 to 10 requests per second. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free and keyless. Without a key more than 3 requests per second from one IP gets an error; a key allows 10 per second.
- NCBI asks large jobs to run on weekends or between 9 PM and 5 AM US Eastern on weekdays, and to send tool and email parameters identifying the caller.
- Answers are XML unless retmode=json, which esearch, esummary and einfo support; efetch does not return JSON.
- The usual flow is search (IDs) then summary or fetch with those IDs.
