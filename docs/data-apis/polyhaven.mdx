## Setup

| Variable | | What it is |
|---|---|---|
| `POLYHAVEN_USER_AGENT` | optional | A unique User-Agent naming your software, which Poly Haven's terms require on every call so it can group your app's requests; the default names WebRouter, so set your own with contact details for heavy use. Default `WebRouter (+https://github.com/Nimbleway/webrouter)`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free and keyless, including commercial use. The terms require a unique User-Agent (or Referer) naming your software on every call: set POLYHAVEN_USER_AGENT.
- Surfacing Poly Haven content through the live API requires a visible credit to Poly Haven in your product; the downloaded CC0 assets themselves need no attribution.
- Asset types are hdris, textures and models. Use search for relevance, then assets or info for metadata, then files for download URLs.
