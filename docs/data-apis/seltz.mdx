## Setup

| Variable | | What it is |
|---|---|---|
| `SELTZ_API_KEY` | required | A Seltz API key (console.seltz.ai/api-keys). Sent in the x-api-key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Prices follow tier (search, fetch), model (answer) and effort (agent); unknown tier names are rejected rather than defaulted. New keys come with 20,000 search credits (seltz.ai).
- Creating, editing and deleting monitors are writes and are not in this entry.
- Web search (POST /v1/search) is served by search(provider="seltz"), so it is not listed here.
