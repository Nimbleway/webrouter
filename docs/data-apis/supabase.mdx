## Setup

| Variable | | What it is |
|---|---|---|
| `SUPABASE_ACCESS_TOKEN` | required | A Supabase personal access token (or an OAuth token), sent as a Bearer token. Prefer a scoped token; a classic one has full account rights. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Rate limit: 120 requests a minute per user, per project or organisation, per endpoint; some are stricter. X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset (seconds) come back; over it answers 429.
- This is the management API on api.supabase.com, not a project's own REST/Auth/Storage API at &lt;ref&gt;.supabase.co, which needs the project's keys and a per-project host.
- Several endpoints (SQL query, advisors, database context) are marked experimental or beta and may change.
