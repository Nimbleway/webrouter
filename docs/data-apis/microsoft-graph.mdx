## Setup

| Variable | | What it is |
|---|---|---|
| `MS_GRAPH_CLIENT_ID` | required | Application (client) id of an Entra ID app registration. |
| `MS_GRAPH_CLIENT_SECRET` | required | A client secret of that app registration (web/confidential client). |
| `MS_GRAPH_REFRESH_TOKEN` | required | A refresh token from the authorization code flow, requested with offline_access and the Graph permissions the calls need (User.Read.All, GroupMember.Read.All, LicenseAssignment.Read.All, Reports.Read.All, AuditLog.Read.All). |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Calls act as the signed-in user behind the refresh token (delegated permissions): besides the app's consented Graph permissions, that user needs an Entra role that can read the data (e.g. Global Reader or Reports Reader for reports and sign-ins).
- Lists page with @odata.nextLink: call that full URL for the next page; &#36;skip is not supported on directory objects.
- Advanced queries (&#36;search, &#36;count, most &#36;filter/&#36;orderby on users, groups and members) need the ConsistencyLevel: eventual header and &#36;count=true.
- Usage reports answer 302 to a short-lived pre-signed CSV download, not JSON.
- Throttled requests get 429 with a Retry-After header.
