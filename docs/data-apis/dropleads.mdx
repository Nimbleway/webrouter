## Setup

| Variable | | What it is |
|---|---|---|
| `DROPLEADS_API_KEY` | required | a DropLeads API key (Settings &gt; API Keys in your DropLeads account; shown once) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credits: searching people and counting are free and return masked data (no email or phone); verified enrich 0.2 credits per verified lead; simple enrich (no verification) 0.2 per lead; company search 0.1 per company returned; company enrich 0.1 per company found.
- Typical flow: lead search or count with filters, check the cost with dropleads.leads.export_cost, then enrich chosen lead ids with dropleads.leads.enrich (verified) or dropleads.leads.simple_enrich.
- Bodies are JSON with a filters object (combined with AND) and, for searches, a pagination object &#123;page, limit&#125;. Most array filters have a parallel *Exclude key.
- The standalone email finder, email verifier and mobile finder (POST /email-finder, /email-verifier, /mobile-finder) live on a different host, api.dropleads.io, and are not in this entry.
- This reference host also accepts 'Authorization: Bearer &lt;token&gt;' in place of X-API-Key.
