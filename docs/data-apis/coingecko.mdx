## Setup

| Variable | | What it is |
|---|---|---|
| `COINGECKO_DEMO_API_KEY` | some calls | a CoinGecko Demo (free) API key (coingecko.com/en/developers/dashboard); use with host api.coingecko.com |
| `COINGECKO_PRO_API_KEY` | some calls | a CoinGecko paid-plan API key (coingecko.com/en/developers/dashboard); use with host pro-api.coingecko.com |
| `COINGECKO_HOST` | optional | api.coingecko.com for the Demo (free) plan, pro-api.coingecko.com for paid plans. Default `api.coingecko.com`. One of `api.coingecko.com`, `pro-api.coingecko.com`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Set COINGECKO_HOST to pro-api.coingecko.com for a paid key; the default api.coingecko.com is the Demo (free) host. Each key is sent only to its own host: the Demo key to api.coingecko.com, the paid key to pro-api.coingecko.com.
- Each successful call spends 1 monthly credit; rate limits depend on the plan.
- Some endpoints and parameters need Analyst plan or above; the Demo plan covers a subset.
- Coin ids are CoinGecko slugs (bitcoin, not BTC); look them up with coingecko.search or coingecko.coins.list.
