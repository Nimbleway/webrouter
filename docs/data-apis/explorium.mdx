## Setup

| Variable | | What it is |
|---|---|---|
| `EXPLORIUM_API_KEY` | required | An Explorium AgentSource API key (admin.explorium.ai). Sent in the api_key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Calls spend credits by action (the price list is on the admin pricing page); check the balance with explorium.credits.get.
- Rate limit: 200 queries a minute per key, where each entity in a batch counts as one query (50 ids = 50 queries). 429 carries Retry-After.
- Most calls take Explorium business ids: get them from explorium.businesses.match first, or pass businesses_to_match to an enrichment.
- This entry uses the v2 API. Async jobs, dataset uploads, event enrollments, webhooks, prospects and AI research are not in it.
