## Setup

| Variable | | What it is |
|---|---|---|
| `SMARTRECRUITERS_API_KEY` | some calls | Optional SmartRecruiters API key, sent as x-smarttoken. Public postings need no key. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keyless for public postings. companyIdentifier is the company's SmartRecruiters id, as in its careers URL (jobs.smartrecruiters.com/&lt;companyIdentifier&gt;).
- Only postings the company published through SmartRecruiters are returned; internal postings need an OAuth token with internal_postings_read, which this entry does not set up.
- Paging is offset + limit (max 100); the response gives totalFound.
