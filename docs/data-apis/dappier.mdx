## Setup

| Variable | | What it is |
|---|---|---|
| `DAPPIER_API_KEY` | required | a Dappier API key (platform.dappier.com &gt; Settings &gt; Profile &gt; API Keys). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Models are picked by ID from the Dappier Marketplace: AI models start with am_ (real-time search), data models with dm_ (article recommendations). Price depends on the model.
- Both calls are reads over POST.
- Publisher analytics and the ZeroClick-signed variants are in the API but not in this entry.
