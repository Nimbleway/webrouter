## Setup

| Variable | | What it is |
|---|---|---|
| `RAINFOREST_API_KEY` | required | A Rainforest API key (app.rainforestapi.com), sent as the api_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call is GET /request with type naming the data; each endpoint here fixes type.
- Billed in credits: 1 per page retrieved, more for some options; request_info.credits_used and credits_remaining in each answer show the cost.
- Give asin (or gtin) with amazon_domain. The vendor's url parameter, which takes a raw Amazon page URL, is left out.
- Calls are run against Amazon in real time when made, not served from a stored index.
