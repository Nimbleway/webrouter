## Setup

| Variable | | What it is |
|---|---|---|
| `MORPHOSOURCE_API_KEY` | some calls | Optional API key of a MorphoSource account, sent as the raw Authorization header; needed for downloads, private records you can access and project-manager statistics. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Searching and reading published records is keyless; a key adds private records the account may view.
- Search results are paged: page from 1, per_page 10 by default, at most 1000.
- Filters are facets named f.&lt;field&gt; (f.taxonomy_name, f.media_type ...), with the same values as the website's search pages.
- Media and physical object ids are 9-digit strings, e.g. 000200043; keep the leading zeros.
