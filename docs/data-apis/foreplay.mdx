## Setup

| Variable | | What it is |
|---|---|---|
| `FOREPLAY_API_KEY` | required | A Foreplay API key (app.foreplay.co &gt; API overview). |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credits: 1 per ad returned on ad endpoints (a page of 250 ads costs 250), 1 per call on brand endpoints whatever the count; empty and error responses are free; usage is free. X-Credits-Remaining is on every response.
- Ad lists page by cursor: pass metadata.cursor from the previous response.
- Each ad carries foreplay_url, the link to view it in Foreplay.
- Swipe file, boards and Spyder (your own saved and tracked brands) are not in this entry.
