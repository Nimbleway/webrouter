## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_ANALYTICS_CLIENT_ID` | required | the OAuth client id of a Google Cloud OAuth app with the Google Analytics Data API enabled (Google Cloud console &gt; APIs & Services &gt; Credentials) |
| `GOOGLE_ANALYTICS_CLIENT_SECRET` | required | that OAuth app's client secret |
| `GOOGLE_ANALYTICS_REFRESH_TOKEN` | required | a refresh token minted with that OAuth app for the scope https://www.googleapis.com/auth/analytics.readonly |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: reads properties the signed-in Google user can access. GA4 only; Universal Analytics properties are gone.
- Property ids are digits only; the path takes them as properties/&#123;id&#125; and this catalog adds the prefix.
- Report requests are POSTs but only read data.
- Row counts and offsets are strings (int64) in the JSON. Default limit 10,000, maximum 250,000 per request. Page with offset.
- Properties have token-based quotas; set returnPropertyQuota: true to see what a call used.
