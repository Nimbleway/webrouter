## Setup

| Variable | | What it is |
|---|---|---|
| `CLOSE_API_KEY` | required | a Close API key (Settings &gt; Developer &gt; API Keys); it acts as its user in one organization |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Ids carry a type prefix: lead_, cont_, oppo_, user_, orga_, stat_, save_.
- List calls page with _limit and _skip; advanced-filter search pages with a cursor that expires after 30 seconds. Custom field values appear as custom.cf_... keys.
- Rate limits are per endpoint group, per API key, with an organization limit three times higher. On 429 wait the rate_reset seconds the answer gives; the RateLimit header shows limit, remaining and reset.
- Money values (opportunity value, revenue) are in cents.
