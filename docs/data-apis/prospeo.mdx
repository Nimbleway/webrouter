## Setup

| Variable | | What it is |
|---|---|---|
| `PROSPEO_API_KEY` | required | A Prospeo API key (Prospeo dashboard &gt; API). Sent in the X-KEY header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Almost every call is a POST with a JSON body; bodies carry the filters or the person to match.
- Charged only on results: 1 credit per email found, 10 per mobile, 1 per search page with results; repeats within 90 days (enrich) or 30 days (search pages) are free.
- Search results never include emails or mobiles; enrich a person to get them.
