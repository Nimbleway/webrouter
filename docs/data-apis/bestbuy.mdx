## Setup

| Variable | | What it is |
|---|---|---|
| `BESTBUY_API_KEY` | required | A free Best Buy developer API key (developer.bestbuy.com), sent as the apiKey query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Products, stores and categories answer XML unless format=json is passed; recommendations and open box are JSON only.
- Search expressions go inside parentheses in the path: products(search=oven&salePrice&lt;500), with & for AND, | for OR, in(a,b) and trailing * wildcards. Attribute names are case-sensitive.
- Past 10 pages use cursorMark=* and then the returned nextCursorMark instead of page.
- A 403 means a bad key or the call quota is exceeded; prefer one in(...) query over many single lookups to avoid per-second errors.
- Links in responses (url, addToCartUrl) expire after seven days.
