## Setup

| Variable | | What it is |
|---|---|---|
| `EODHD_API_TOKEN` | required | an EODHD API token (eodhd.com/cp/settings); the token value demo works for six tickers |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Tickers are CODE.EXCHANGE (AAPL.US); for US stocks the .US suffix may be omitted on EOD requests.
- Output is CSV unless you send fmt=json (fundamentals is JSON only).
- Free plan: 20 calls a day with one year of data; each request costs API calls and failed requests can still be billed.
- The demo token (api_token=demo) works on six tickers: AAPL.US, TSLA.US, BTC-USD.CC, VTI.US, AMZN.US, EURUSD.FOREX.
