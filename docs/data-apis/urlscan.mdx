## Setup

| Variable | | What it is |
|---|---|---|
| `URLSCAN_API_KEY` | some calls | A urlscan.io API key (created in your urlscan.io user account), sent in the api-key header. Without one, quotas are minimal. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Quotas are per action (search, result...) and per minute, hour and day, with fixed windows resetting on the minute, hour and midnight UTC; only HTTP 200s count. X-Rate-Limit-* headers report the window closest to running out; over it is a 429.
- Submitting a scan is left out on purpose: a scan publishes the URL's page to urlscan.io (public by default). So are visibility changes, saved searches, subscriptions, incidents and live scans.
- Queries use Elasticsearch query-string syntax with case-sensitive field names (page.domain:example.com); escape reserved characters and narrow with a date filter such as date:&gt;now-7d.
