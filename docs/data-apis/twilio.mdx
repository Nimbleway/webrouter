## Setup

| Variable | | What it is |
|---|---|---|
| `TWILIO_ACCOUNT_SID` | required | Your Twilio Account SID (AC...), from the Console home page. |
| `TWILIO_AUTH_TOKEN` | required | The account's Auth Token, from the Console home page. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Account-scoped paths take the Account SID as AccountSid: pass the same AC... value the credentials use.
- Paths end in .json; leave it off and the API answers XML.
- Lists page by PageSize (max 1000) and PageToken; follow next_page_uri from the answer rather than building the token.
- Dates in list filters are GMT YYYY-MM-DD; DateSent&lt; and DateSent&gt; give a range.
