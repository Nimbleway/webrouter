## Setup

| Variable | | What it is |
|---|---|---|
| `WEATHERAPI_API_KEY` | required | A WeatherAPI.com API key (account dashboard). Sent as the key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Plan gates: forecast is 3-14 days depending on plan; future.json (14-300 days ahead) is Pro+; history end_dt ranges are Pro+; minutely rain is Starter+; alerts are limited on Free.
- Dates are yyyy-MM-dd; unixdt/unixend_dt are the Unix-timestamp alternatives (never send both forms).
