## Setup

| Variable | | What it is |
|---|---|---|
| `SOCRATA_APP_TOKEN` | some calls | Optional Socrata app token, sent in the X-App-Token header. Without one, calls share a low per-IP throttle; with one they get their own pool. |
| `SOCRATA_REGION` | optional | us for North American portals, eu for all others. Default `us`. One of `us`, `eu`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free and keyless for public assets. Throttled calls answer 429.
- Unknown parameters are treated as custom-metadata filters, so a misspelt one (domain instead of domains) silently returns nothing.
- Repeating a parameter is a union (tags=fire&tags=commission); different parameters intersect.
- This entry covers discovery only. A dataset's rows are queried on its own portal (https://&lt;portal&gt;/api/v3/views/&lt;four-by-four&gt;/query.json, or the older /resource/&lt;id&gt;.json) -- a host per portal that this format cannot name. Each search result carries the portal domain and the four-by-four id.
