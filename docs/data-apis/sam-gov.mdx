## Setup

| Variable | | What it is |
|---|---|---|
| `SAM_GOV_API_KEY` | required | A personal public API key from the Account Details page of a SAM.gov account. Sent as the api_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Daily request limits depend on the account: a personal key of a non-federal user with no SAM.gov role gets 10 requests a day; with a role, or a federal user, 1,000.
- Dates are MM/dd/yyyy, not ISO.
- This entry reads public data only; FOUO and sensitive entity data need a federal system account.
