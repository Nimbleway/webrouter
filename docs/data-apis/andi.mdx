## Setup

| Variable | | What it is |
|---|---|---|
| `ANDI_API_KEY` | required | an Andi API key (console.andiai.com). Sent in the x-api-key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Outcome-based pricing: each call is charged for the work it did plus a per-token rate on returned content. Every JSON response reports its cost in metrics.cost_dollars (frontmatter cost_dollars with format=context). An empty balance answers 402.
- Rate limits are per key, per endpoint, per second, set in the console; responses carry X-RateLimit-* headers and 429 carries Retry-After.
