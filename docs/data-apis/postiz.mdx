## Setup

| Variable | | What it is |
|---|---|---|
| `POSTIZ_API_KEY` | required | A Postiz API key (Postiz Settings), or an OAuth token starting with pos_. Sent as the raw Authorization header value, with no Bearer prefix. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Postiz Cloud only; a self-hosted instance serves the same API at https://&lt;your-domain&gt;/api/public/v1, which this entry does not reach.
- The API says integration where the UI says channel: every integration id comes from GET /integrations, never the platform name.
- Rate limit: 100 requests per hour on Cloud, counted on the create-post endpoint only; batch several posts in one call.
- A DELETE that answers 404 means already deleted.
