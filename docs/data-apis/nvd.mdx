## Setup

| Variable | | What it is |
|---|---|---|
| `NVD_API_KEY` | some calls | Optional NVD API key (nvd.nist.gov/developers/request-an-api-key), sent in the apiKey header; it raises the rate limit tenfold. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Rate limit per rolling 30 seconds: 5 requests without a key, 50 with one; NIST still asks for a pause of a few seconds between requests. Excess requests are blocked by the firewall.
- Any date range (published, modified, KEV, change) must have both ends and span at most 120 consecutive days.
- Paging is offset-based: read totalResults and repeat with startIndex advanced by resultsPerPage.
- Value-less flags (hasKev, noRejected, keywordExactMatch, isVulnerable and similar) are documented as bare query keys and are not in these entries.
- NIST asks applications to show: 'This product uses data from the NVD API but is not endorsed or certified by the NVD.'
