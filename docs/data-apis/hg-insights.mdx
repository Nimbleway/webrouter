## Setup

| Variable | | What it is |
|---|---|---|
| `HG_API_KEY` | required | An HG Insights v2 API key (admin.hginsights.com &gt; Settings &gt; API Keys, admin only; starts hg_v2_). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Needs an HG Platform subscription with credits. Enrich, hierarchy, intent and contract calls spend credits by the data returned; match, search, catalog and credits are free but need a positive balance. Out of credits answers 402.
- Re-enriching the same company within the 12-month contract is free; intent calls are charged every time.
- Rate limits by plan: Sandbox 2 requests a second and 1,000 a day, Standard 25 a second and 50,000 a day. A batch counts as one request. 429 comes with x-ratelimit-reset.
- Company ids are hex strings; get them from hg-insights.companies.match or search, or pass domains.
