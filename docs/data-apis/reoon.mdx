## Setup

| Variable | | What it is |
|---|---|---|
| `REOON_API_KEY` | required | A Reoon Email Verifier API key (created on the API page of the Reoon dashboard). Sent as the key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credits come in two pools, daily and instant; the balance call shows both.
- Creating a bulk task takes the key and up to 50,000 emails in a JSON body and is not in this entry; the result call reads a task created elsewhere (dashboard or API).

<Note>
- Quick mode does not check the mailbox: any address at a domain that accepts mail comes back valid. Its statuses are valid, invalid, disposable, spamtrap.
- Power mode statuses: safe, invalid, disabled, disposable, inbox_full, catch_all, role_account, spamtrap, unknown.
- Not for bulk work: keep to 5 concurrent calls at most.
</Note>
