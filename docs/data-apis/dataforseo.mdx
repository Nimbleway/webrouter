## Setup

| Variable | | What it is |
|---|---|---|
| `DATAFORSEO_LOGIN` | required | your DataForSEO API login (from the API Access page of your DataForSEO dashboard) |
| `DATAFORSEO_PASSWORD` | required | your DataForSEO API password (from the API Access page of your DataForSEO dashboard; not your web login password) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every POST takes a JSON ARRAY of task objects, e.g. [&#123;"keyword": "...", "location_code": 2840, "language_code": "en"&#125;]; the params below describe one task object. Live calls accept one task per call.
- Billing is prepaid in USD per task (the cost field of each answer); minimum top-up is &#36;50 and new accounts get &#36;1 trial credit. Prices vary by endpoint and mode: Google organic SERP is &#36;0.0006 per SERP (standard queue), &#36;0.0012 (priority) or &#36;0.002 (live).
- Live endpoints answer in one call (about 6 seconds for SERP); the queue pattern is task_post, then tasks_ready, then task_get. Results are kept 30 days.
- Answers wrap a tasks array; check each task's status_code and status_message as well as the HTTP status.
- Most calls need a location and a language; give either the code or the full name of each. Valid values come from each product's locations and languages endpoints.
- pingback_url and postback_url are left out: each sends the result to an address the caller picks; poll tasks_ready instead.
