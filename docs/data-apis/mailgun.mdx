## Setup

| Variable | | What it is |
|---|---|---|
| `MAILGUN_API_KEY` | required | A Mailgun API key (Mailgun dashboard &gt; API Security). Sent as HTTP Basic auth with the username 'api'. |
| `MAILGUN_API_HOST` | optional | API host: api.mailgun.net (US) or api.eu.mailgun.net for an EU account. Default `api.mailgun.net`. One of `api.mailgun.net`, `api.eu.mailgun.net`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Only the Validate (address verification) API is in this entry; nothing here sends mail. Starting, promoting or cancelling bulk jobs and list health previews is left out.
- Validation is limited to a set number of active requests at a time; a 429 means wait and retry.
