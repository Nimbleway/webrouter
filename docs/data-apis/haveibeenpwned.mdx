## Setup

| Variable | | What it is |
|---|---|---|
| `HIBP_API_KEY` | some calls | An HIBP API key (haveibeenpwned.com/API/Key), sent in the hibp-api-key header. The breach catalogue calls need none. |
| `HIBP_USER_AGENT` | optional | The User-Agent HIBP requires on authenticated calls, naming the consuming application; a missing one can be a 403. Default `web-router`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Breach, paste and stealer-log searches are rate limited per key at the plan's requests per minute (subscription.status returns it as Rpm); over it is a 429 with a retry-after header in seconds. Add a short delay on top of the limit.
- Which calls a key may use depends on its plan: the range search needs Pro or High RPM; domain search only works for domains verified on the dashboard.
- A 404 on a search means nothing was found.
- Stealer-log, domain-verification and Pwned Passwords endpoints are not in this entry.
