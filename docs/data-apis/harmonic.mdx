## Setup

| Variable | | What it is |
|---|---|---|
| `HARMONIC_API_KEY` | required | Your team's Harmonic API key (console.harmonic.ai). Sent in the apikey header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Only 200 responses count toward the plan's usage quota; 402 means over quota on that endpoint.
- Rate limit: 10 requests a second for most endpoints; natural-language search 5 a minute. 429 when exceeded.
- Lists page by cursor: size (default 50) and the next value from page_info.
- Detailed funding rounds and investor data are a paid add-on. Scout research, saved-search writes, the Workspace API and bulk email jobs are not in this entry, nor is company enrich (POST /companies): for a company Harmonic does not hold yet it starts a billed enrichment job. Look a company up by Harmonic id with harmonic.companies.get, or find it with the search calls.
