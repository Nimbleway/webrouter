| Variable | | What it is |
|---|---|---|
| `SALESQL_API_KEY` | required | A SalesQL API key (Settings &gt; API Access; Professional and Premium plans). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Person enrichment spends credits; organization enrichment and the allowance call are free. salesql.account.allowance gives the rate limits.
- Bulk person and organization enrichment and bulk verification jobs are not in this entry.
