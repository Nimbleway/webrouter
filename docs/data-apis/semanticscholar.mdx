## Setup

| Variable | | What it is |
|---|---|---|
| `SEMANTIC_SCHOLAR_API_KEY` | some calls | Optional Semantic Scholar API key, requested at semanticscholar.org/product/api and sent by email; sent in the x-api-key header (case-sensitive). |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Most endpoints work keyless, but keyless traffic shares one pool of 1,000 requests per second across all unauthenticated users, so 429s are common; a new key starts at 1 request per second on all endpoints.
- Without fields, responses carry only paperId and title (or authorId and name).
- Papers have two IDs: paperId (string) and corpusId (integer, used by the datasets).
