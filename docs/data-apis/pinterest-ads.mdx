## Setup

| Variable | | What it is |
|---|---|---|
| `PINTEREST_APP_ID` | required | the app id of your Pinterest app (developers.pinterest.com &gt; My apps) |
| `PINTEREST_APP_SECRET` | required | that app's secret key |
| `PINTEREST_REFRESH_TOKEN` | required | a refresh token for that app with the ads:read scope, from the OAuth authorization-code flow |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: ad accounts the authorizing Pinterest user can access. Needs an approved app with ads access.
- Lists page with bookmark: pass the answer's bookmark back as bookmark until it is null.
- Analytics date ranges are capped at 90 days and cannot start more than 90 days back.
- Reads here; creating or updating ads is not included.
