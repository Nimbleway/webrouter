## Setup

| Variable | | What it is |
|---|---|---|
| `CRUNCHBASE_API_KEY` | required | your Crunchbase API key (Crunchbase API integrations page &gt; Show Key); API access comes through the Crunchbase sales team |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Read-only API. Limits per key: 200 requests per minute and 3 requests in flight at once; 429 may carry Retry-After.
- Your key only returns the fields and collections of your licensed package.
- Search pages with after_id (the last result uuid); entity cards hold at most 100 items, then page with organization.card.
