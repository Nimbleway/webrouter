## Setup

| Variable | | What it is |
|---|---|---|
| `ADZUNA_APP_ID` | required | Your Adzuna application ID (developer.adzuna.com &gt; Dashboard). Sent as the app_id query parameter. |
| `ADZUNA_APP_KEY` | required | Your Adzuna application key, from the same page. Sent as the app_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Without an Accept header the API answers JSONP; this entry sends Accept: application/json.
- The free key is for evaluation. Commercial use is a 14-day trial, then needs a licence from Adzuna; limits per plan show in your account.
- Search returns only a snippet of each job description, and redirect_url points to the ad on Adzuna.
- Salaries are in the country site's own currency; a job with salary_is_predicted set carries an Adzuna estimate, not an advertised figure.
