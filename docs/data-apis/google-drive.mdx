## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_DRIVE_CLIENT_ID` | required | the OAuth client id of a Google Cloud OAuth app with the Google Drive API enabled (Google Cloud console &gt; APIs & Services &gt; Credentials) |
| `GOOGLE_DRIVE_CLIENT_SECRET` | required | that OAuth app's client secret |
| `GOOGLE_DRIVE_REFRESH_TOKEN` | required | a refresh token minted with that OAuth app for https://www.googleapis.com/auth/drive.readonly (or drive.metadata.readonly for metadata only) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: sees what the Google user who granted the refresh token can see. drive.readonly is a restricted scope; an app used outside its own Google Workspace may need Google's verification.
- Responses are minimal by default; set fields to get more than id, name and mimeType (and nextPageToken for paging).
- Google Docs, Sheets and Slides have no bytes to download; export them. Other files download with alt=media.
