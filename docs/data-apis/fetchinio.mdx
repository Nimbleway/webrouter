## Setup

| Variable | | What it is |
|---|---|---|
| `FETCHIN_API_KEY` | required | A Fetchin API key (fetchin.io dashboard &gt; API keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credit-based: a free account gets 1,000 credits once; plans and pay-as-you-go add more. Most calls cost 1 credit, a few cost more (stated per endpoint). account.subscription shows what is left.
- Self-serve plans allow 5 requests per second.
- Paging differs by endpoint: feeds use paginationToken, search uses cursor, comments and reactions use a start offset.
- Accepts profile and post URLs as well as URNs; URNs are more stable.
