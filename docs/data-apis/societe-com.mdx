## Setup

| Variable | | What it is |
|---|---|---|
| `SOCIETE_COM_API_KEY` | required | A Societe.com API Pro token (pro account, then ask api-pro-support@societe.com). Sent as X-Authorization: socapi &lt;token&gt;. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Calls are only accepted from IP addresses allowed in your Societe.com account; any other IP gets 401 or 403.
- Each successful call spends credits (costs per route below; 402 when out). Failed calls cost nothing, except failures with valid parameters.
- Rate limit: 60 requests a minute by default (Highrate option for more); 429 when exceeded.
- JSON by default; contenttype=xml returns XML. Dates in answers are AAAAMMJJ. Field names are French.
