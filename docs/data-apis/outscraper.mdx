## Setup

| Variable | | What it is |
|---|---|---|
| `OUTSCRAPER_API_KEY` | required | An Outscraper API key (app.outscraper.com &gt; API key). Sent in the X-API-KEY header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Calls are asynchronous by default: they return &#123;id&#125; and the results come from requests.get, usually within 1-3 minutes. Pass async=false to wait for the results in the same call (best with small limits).
- Results stay available for 4 hours after a request completes; then its status reads Pending again.
- Most endpoints batch: repeat query (query=a&query=b, up to 1000) and results come back as one list per query.
- Usage is counted per item returned (place, review...); a search that finds nothing still uses one item. Average throughput is about 20 queries a second.
- Tasks (UI jobs), the business catalog and the other ~90 site scrapers (Yelp, Trustpilot, Indeed, Zillow...) are not in this entry; DELETE /requests/&#123;id&#125; terminates a request.
