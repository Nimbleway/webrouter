## Setup

| Variable | | What it is |
|---|---|---|
| `YELP_API_KEY` | required | A Yelp Places API key (yelp.com/developers &gt; Manage App), sent as Authorization: Bearer &lt;key&gt;. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Daily call limits depend on the plan (the Starter trial allows 300 calls per 24 hours, reset at midnight UTC); RateLimit-Remaining and RateLimit-ResetTime headers report what is left. Too many calls per second answer 429 TOO_MANY_REQUESTS_PER_SECOND.
- Businesses with no reviews are not returned by search, phone search or reviews.
- Yelp's API terms carry display requirements (attribution, linking back to Yelp) for data you show.
