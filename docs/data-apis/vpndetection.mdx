## Setup

| Variable | | What it is |
|---|---|---|
| `VPNDETECTION_API_KEY` | some calls | a VPNDetection API key (vpndetection.io console &gt; API keys). Optional: without one the free Unlimited plan answers single lookups |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- No key is needed: the free Unlimited plan answers every single lookup with is_vpn, is_tor and is_relay, the tor and relay detail objects with their provider, is_bot, is_anycast, is_bogon, hostname, country-level location and the announcing ASN with its type (isp, hosting, business...), prefix and RPKI status (terms: https://vpndetection.io/terms#no-key).
- A field missing from an answer is one the plan does not include, never false: the proxy flags (is_resproxy, is_dcproxy, is_mobproxy, is_pubproxy), is_hosting, is_cdn, the vpn object (which VPN it is), city and coordinates need a paid plan. For hosting traffic on the free plan, read asn.type.
- Private and reserved addresses answer 200 with is_bogon true, not an error. A 429 carries Retry-After.
