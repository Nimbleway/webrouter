## Setup

| Variable | | What it is |
|---|---|---|
| `CORESIGNAL_API_KEY` | required | a Coresignal API key from the dashboard (https://dashboard.coresignal.com) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Two-step flow: a search returns only record IDs (1,000 per page); collect or enrich returns the data and spends credits (402 when out of credits; x-credits-remaining header shows the balance).
- Data API rate limit is 5 to 100 requests per second depending on the plan.
- Coresignal also offers jobs, posts and other datasets under the same host; only company and employee endpoints are listed here.
