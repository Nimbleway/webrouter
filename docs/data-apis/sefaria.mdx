## Notes

- Keyless. Texts are addressed by refs (Genesis 1:1, Berakhot 2a); spaces in a ref are URL-encoded in the path.
- Each text version carries its own licence (e.g. CC-BY-SA, public domain); see the version's license field before reuse.
- find-refs is asynchronous: it returns a task_id with HTTP 202, then poll GET /api/async/&#123;task_id&#125; until it holds the result.
