## Setup

| Variable | | What it is |
|---|---|---|
| `RECENTFUNDING_API_KEY` | required | A Recent Funding API key (rf_live_..., free from recentfunding.com/dashboard/). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free keys: 10 requests a day, data at least 14 days old, no stealth companies (asking for one is 403 plan_required). Pay as you go is &#36;0.10 a call; Pro and Max are monthly quotas. X-RateLimit-* headers report what is left.
- Paging is limit + offset; list answers give next_offset (null on the last page).
- Unknown query parameters are refused with 400.
- Every amount links to its source (e.g. raise_source_url); an amount with no source is not shown.
- The docs ask callers to send X-On-Behalf-Of naming who they fetch for; this entry does not send it.
