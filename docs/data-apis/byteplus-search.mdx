## Setup

| Variable | | What it is |
|---|---|---|
| `BYTEPLUS_SEARCH_API_KEY` | required | a Searchinfinity API key (Searchinfinity console &gt; API Key). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Request and response fields are PascalCase (Query, Count, Result.WebResults...).
- Postpaid credits at &#36;0.006 each: Flux search 1 credit (&#36;0.006) per request, Omnira search half a credit (&#36;0.003), Fetch a sixth (&#36;0.001).
- Errors come back in ResponseMetadata.Error with numeric codes: 700901 invalid key, 700429 QPS exceeded, 10403 service not enabled or free quota exhausted, 10400 bad parameter.
- All three calls are reads over POST.
