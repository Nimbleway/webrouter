## Setup

| Variable | | What it is |
|---|---|---|
| `IP2LOCATIONIO_API_KEY` | some calls | An IP2Location.io API key (free plan sign-up at ip2location.io). Sent as a Bearer token. IP geolocation works without one; WHOIS and hosted domains need it. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Without a key, geolocation allows 1,000 queries a day, reset at 00:00 UTC; a Free Plan key raises that to 50,000 a month.
- Which fields come back depends on the plan: the basic response is location, time zone, ASN and is_proxy; higher plans add ISP, domain, usage type, mobile carrier, proxy details, fraud score and more.
