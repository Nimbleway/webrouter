## Notes

- search2 and fetchOpportunity are keyless; other Grants.gov REST APIs need a key issued through the Help Desk and are not listed here.
- Both calls are reads over POST with a JSON body, and wrap the answer as &#123;errorcode, msg, token, data&#125;; errorcode 0 means success.
- Multi-value filters are one string joined with '|' (e.g. oppStatuses 'forecasted|posted').
