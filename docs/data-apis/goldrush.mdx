## Setup

| Variable | | What it is |
|---|---|---|
| `GOLDRUSH_API_KEY` | required | A GoldRush API key (goldrush.dev platform). Sent as an Authorization Bearer header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Calls cost API credits, per call or per item returned (listed per endpoint); an item costs only when it is returned, a call only on a 200.
- Plans: 14-day free trial with 25,000 credits a month at 4 requests/second; paid plans raise both.
- Responses wrap the payload: check error before reading data; data.items holds the rows.
- Pages are counted from 0, up to 100 items each by default.
- Balances are raw integer strings; divide by 10^contract_decimals.
