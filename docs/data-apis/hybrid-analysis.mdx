## Setup

| Variable | | What it is |
|---|---|---|
| `HYBRID_ANALYSIS_API_KEY` | required | A Hybrid Analysis API key (profile &gt; API key tab &gt; Create API key), sent in the api-key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keys have an authorization level (restricted, default, elevated, super); a free unvetted account gets a restricted key, enough for search and report reads.
- The key's quota is reported in the response headers.
- File and URL submission, quick scans, overview refreshes, abuse reports and sample or dropped-file downloads are not in this entry.
