## Notes

- Keyless and free.
- Documentation and labels are in Portuguese; agregado = SIDRA table, variavel = measure, classificacao = dimension, categoria = member, localidade = place.
- Geographic levels include N2 region, N3 state (UF), N6 municipality and N7 metropolitan region; BR is Brazil. An aggregate's metadata lists the levels it covers.
- Several IDs in one path or query value are joined with |.
