## Setup

| Variable | | What it is |
|---|---|---|
| `BRANDFETCH_API_KEY` | required | A Brandfetch API key (developers dashboard), sent as a Bearer token. Needed for every call except brand search. |
| `BRANDFETCH_CLIENT_ID` | some calls | A Brandfetch client id, needed only for the Brand Search API (passed as the c query parameter). |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Quota: one credit per Brand API, Brand Context API or Transaction API request; a 404 also uses a credit, 400 and 204 do not. Logo and image fetches from the returned CDN URLs are free. 429 quota_exceeded when the month's quota is used up.
- Brand search authenticates with a client id (c query parameter) instead of the API key.
- Pass cachedOnly=true to avoid a live index (and a charge) for brands Brandfetch has not seen.
