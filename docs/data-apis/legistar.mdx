## Setup

| Variable | | What it is |
|---|---|---|
| `LEGISTAR_API_TOKEN` | some calls | Only some clients require a token, issued by that client (the city or county), not by Granicus. Sent as the token query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every path starts with the client name, the jurisdiction's Legistar site name (e.g. seattle, chicago, nyc); an unauthorized answer means that client requires a token.
- Lists return at most 1000 items. Page and filter with OData v3 query options: &#36;top, &#36;skip, &#36;filter, &#36;orderby (e.g. &#36;filter=EventDate ge datetime'2014-09-01').
- Only items marked public on the client's site are returned. For a busy client, ordering by id and filtering on id gt the last seen id is more stable than &#36;skip paging.
- Field names are the API's, not the client's customized labels.
