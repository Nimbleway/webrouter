## Setup

| Variable | | What it is |
|---|---|---|
| `SEAMLESS_API_KEY` | required | A Seamless.AI API key (Settings &gt; Public API &gt; API Key; needs Public API access). Sent in the Token header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Search spends one shared credit balance; every response carries what is left in X-PublicAPI-Credits. HTTP 422 means a missing licence or no credits (see code).
- Rate limits are per organization and per endpoint; read X-RateLimit-Limit and X-RateLimit-Reset rather than assuming a number.
- Research (which saves records into your organization), its webhooks, the engagement API and list management are not in this entry.
