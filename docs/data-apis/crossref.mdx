## Notes

- Keyless. Adding mailto=&lt;your email&gt; (or an email in the User-Agent) moves calls to the polite pool: 10 requests per interval and 3 concurrent instead of 5 and 1; the interval is in the x-rate-limit-interval header. 429 means slow down, 403 means blocked.
- Crossref Plus subscribers send their key as the header crossref-api-key: Bearer &lt;key&gt; for 150 requests per interval; not configured here, pass it through vendor_request if you hold one.
- Lists return up to 1000 items (rows). For deep paging use cursor=* and then each response's next-cursor (cursors expire after 5 minutes); offset only reaches 10,000.
- Pass a DOI as written (10.5555/12345678): path values are encoded, so the slash goes as %2F, which the API expects.
