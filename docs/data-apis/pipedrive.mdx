## Setup

| Variable | | What it is |
|---|---|---|
| `PIPEDRIVE_API_TOKEN` | required | a Pipedrive personal API token; it acts as that user and sees what they can see |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every read here is a GET on API v2; no record query needs a POST.
- Paging is a cursor: pass additional_data.next_cursor from the answer as cursor; none means the last page.
- Calls spend API tokens from a company-wide daily budget (30,000 x plan multiplier x seats): about 10 per list, 1 per single item and 20 per search on v2. 429 when the budget is spent, until the daily reset. Burst limits apply per 2 seconds, and search is held to 10 requests per 2 seconds.
- Custom fields come back under 40-character hash keys; map them with pipedrive.deal_fields.list. Stage and pipeline are ids; name them with stages.list and pipelines.list.
- List filters that take several values (ids, status, include_fields, custom_fields) take one comma-separated string.
