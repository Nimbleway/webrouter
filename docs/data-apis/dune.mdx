## Setup

| Variable | | What it is |
|---|---|---|
| `DUNE_API_KEY` | required | A Dune API key with at least Read scope (dune.com settings &gt; API). Sent in the X-Dune-Api-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- API access needs a trial or paid plan; free accounts are view-only.
- Credits: runs are charged for compute used (by engine tier); fetching results is charged per MB exported (2 credits/MB on Plus, 10 on Analyst).
- Rate limits on Plus: 70 requests/minute for runs, 200/minute for reads; Enterprise from 350 and 1000.
- Results stored over 32 GB are truncated; ask with allow_partial_results to read them.
- Running a query (POST /v1/query/&#123;query_id&#125;/execute) is not in this entry: it starts a billed run. The execution calls read runs started elsewhere, such as in the Dune app.
