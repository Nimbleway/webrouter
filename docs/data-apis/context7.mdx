## Setup

| Variable | | What it is |
|---|---|---|
| `CONTEXT7_API_KEY` | some calls | A Context7 API key (context7.com/dashboard; starts with ctx7sk). Optional: search and docs work anonymously at low rate limits; a key raises them and reaches private libraries. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Library ids are URL paths: /owner/repo for GitHub (/vercel/next.js), /&lt;source&gt;/&lt;id&gt; otherwise; pin a version with /owner/repo/&lt;version&gt; or /owner/repo@&lt;version&gt;.
- Typical flow: libs.search to find the id, then docs.context with it; or docs.search in one call when the library is known by name.
- Answers are plain text by default; send type=json for structured results.
- Over the limit answers 429 with Retry-After and RateLimit-Limit/-Remaining/-Reset headers; usage.get shows the month's requests.
