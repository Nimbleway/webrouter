## Notes

- Keyless: the docs state Job Board GET data is public and needs no authentication. Only the application POST (not in this entry) needs a Basic-auth Job Board API key.
- Every call is scoped to one company's board_token; there is no cross-company search. A wrong token returns 404.
- Job ids in /jobs are the job post ids that /jobs/&#123;job_id&#125; takes.
