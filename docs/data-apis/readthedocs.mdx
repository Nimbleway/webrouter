## Setup

| Variable | | What it is |
|---|---|---|
| `READTHEDOCS_TOKEN` | some calls | a Read the Docs API token from your profile settings; needed for private data and your own project list, and it raises the rate limit |
| `READTHEDOCS_DOMAIN` | optional | org for Read the Docs Community (app.readthedocs.org), com for Read the Docs Business (app.readthedocs.com) Default `org`. One of `org`, `com`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Public information needs no token. Unauthenticated calls are limited to 5 per minute, authenticated ones to 60; a token also avoids network-level blocks (403s) from cloud and CI IPs.
- Lists page with limit (default 10) and return count, next and previous; follow next.
- Search and embed return page HTML that is not sanitized; escape it before showing it.
