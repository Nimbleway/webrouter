## Setup

| Variable | | What it is |
|---|---|---|
| `USDA_FDC_API_KEY` | required | A free data.gov API key (fdc.nal.usda.gov &gt; Get an API Key). Sent as the api_key query parameter. DEMO_KEY works for trying it out, at 30 requests an hour and 50 a day per IP. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Rate limit: 1,000 requests per hour per IP by default; exceeding it blocks the key for an hour (429). X-RateLimit-Limit and X-RateLimit-Remaining headers show usage.
- Data is public domain (CC0); USDA asks for citation of FoodData Central.
