## Setup

| Variable | | What it is |
|---|---|---|
| `ETHPLORER_API_KEY` | required | an Ethplorer personal API key (ethplorer.io account, API panel); 'freekey' works for development |
| `ETHPLORER_HOST` | optional | Chain: api.ethplorer.io Ethereum mainnet, api.binplorer.com BNB Chain, api.worldplorer.com World Chain, api.lineaplorer.build Linea. Default `api.ethplorer.io`. One of `api.ethplorer.io`, `api.binplorer.com`, `api.worldplorer.com`, `api.lineaplorer.build`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The shared development key 'freekey' is limited to 2 requests/second, 20/min, 100/hour, 1000/day, 100 operations per response and timestamps at most 30 days old. A free personal key allows 10 requests/second, 1000 operations and 1 year.
- Token values are raw integers in the token's smallest unit, as strings; divide by 10^decimals from the token info.
- History endpoints page backwards with timestamp: pass the oldest timestamp you received to get older operations.
