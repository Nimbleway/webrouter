Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call is a POST with a JSON body to /&lt;tool_name&gt;; reads are still POSTs. A non-empty User-Agent header is required (this entry sends one).
- Completed calls answer HTTP 200 with &#123;results, status: ok|not_found, metadata&#125;. Misses are uncharged but count as a request against fair-use limits shown in metadata.fair_use.
- Plans cap records and requests in rolling 5-hour and weekly windows; some tools are plan-restricted.
- The ad-audience tools (hashed emails, MAIDs) and website scraping are not listed here.
