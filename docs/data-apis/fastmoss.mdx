## Setup

| Variable | | What it is |
|---|---|---|
| `FASTMOSS_API_KEY` | required | The FastMoss client_secret from the developer Console, sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call is a POST with a JSON body, including the reads.
- Answers are &#123;code, msg, data&#125;; check code, not just the HTTP status. 30003 means the access-frequency limit was hit, 30002 a data limit.
- Most list calls take filter, orderby, page (default 1) and pagesize (default 10, max 100), with page x pagesize capped (5000 for searches, 500 for rankings). Range filters are &#123;min, max&#125; objects; time ranges are Unix seconds.
- Money fields are in the region's own currency, so revenue and price filters need a region (or seller_id).
