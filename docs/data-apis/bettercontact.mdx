## Setup

| Variable | | What it is |
|---|---|---|
| `BETTERCONTACT_API_KEY` | required | A BetterContact API key (app.bettercontact.rocks/api_requests). Sent in the X-API-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credits are charged per valid data point returned, once per result however many providers were tried; every result carries credits_consumed and credits_left.
- 100 requests a minute per key (200 on Pro or from 1,000 monthly credits), across all endpoints.
- Webhook delivery is left out: poll the *_result endpoints instead.
