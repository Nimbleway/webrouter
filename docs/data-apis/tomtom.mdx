## Setup

| Variable | | What it is |
|---|---|---|
| `TOMTOM_API_KEY` | required | A TomTom API key (developer.tomtom.com &gt; Dashboard &gt; Keys), sent as the key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Coordinates are latitude first everywhere here: lat,lon in positions, bounding boxes and route locations.
- Search answers page with limit (max 100) and ofs; geocoding caps the whole result set at 2,000 (ofs up to 1,900).
- lat and lon without radius only bias the ranking; add radius (metres) to restrict results to the circle.
- These are the global hosts; South Korea uses kr-api.tomtom.com, which this entry does not cover. TomTom also offers newer Orbis versions of these APIs.
