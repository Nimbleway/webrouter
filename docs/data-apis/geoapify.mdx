## Setup

| Variable | | What it is |
|---|---|---|
| `GEOAPIFY_API_KEY` | required | A Geoapify API key (myprojects.geoapify.com &gt; project &gt; API keys), sent as the apiKey query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billing is in credits; the free plan has 3,000 credits a day. A geocode is 1 credit, a places page 1 credit per 20 places returned, a route 1 credit per waypoint pair plus surcharges.
- Coordinate order differs by call: filter and bias strings are longitude first (circle:lon,lat,radius; rect:lon1,lat1,lon2,lat2; proximity:lon,lat), routing waypoints are latitude first unless prefixed lonlat:, and reverse geocoding takes separate lat and lon.
- Responses are GeoJSON by default; pass format=json for a flat results list where the call offers it.
