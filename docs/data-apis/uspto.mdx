## Setup

| Variable | | What it is |
|---|---|---|
| `USPTO_API_KEY` | required | An Open Data Portal API key (data.uspto.gov &gt; Manage API Key; needs a USPTO.gov account with MFA and a completed ODP profile), sent in the X-API-KEY header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free, but rate limited per key; the limits are on data.uspto.gov/apis/api-rate-limits, which needs a signed-in USPTO.gov account to read. Keys of accounts with an incomplete ODP profile were deactivated in October 2026 and must be reactivated on the Manage API Key page.
- Filed under government rather than science: these are the USPTO's public records of applications, grants and their prosecution history, not research literature.
- Application numbers are digits only (14412875), without slashes or commas. Field names in q, filters, sort and fields are dotted paths such as applicationMetaData.filingDate.
