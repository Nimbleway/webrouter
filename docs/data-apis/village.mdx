## Setup

| Variable | | What it is |
|---|---|---|
| `VILLAGE_API_TOKEN` | required | a Village access token (the token returned by POST /v2/auth/tokens, which you call with your secret key from village.ai/platform &gt; Settings &gt; API Keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Village authenticates with short-lived user tokens: you mint one with POST /v2/auth/tokens (secret-key header plus an external_user_id and email), and it carries an expires_at. Mint it yourself and put it in VILLAGE_API_TOKEN; refresh it when it expires. This entry does not mint tokens, to keep the secret key out of calls.
- Results are about the token's user and their network, not a global database; scope: global widens searches.
- Credit-priced (1 credit = &#36;0.02): searches charge per 10 results plus AI work; cached enrichment costs 0.
- A demo token (demo_token_global) returns anonymized sample data.
- Lists, teams, projects, sequences and webhooks exist but are not listed.
