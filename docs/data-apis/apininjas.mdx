## Setup

| Variable | | What it is |
|---|---|---|
| `APININJAS_API_KEY` | required | An API Ninjas key (api-ninjas.com &gt; My Account). One key works for every API; sent in the X-Api-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The free tier is non-commercial only and hides many fields and options; each API's page lists what needs a premium plan (non-.com domains for WHOIS and DNS, most IP lookup fields, sanctions filters beyond name).
- This entry names a handful of the ~150 APIs; any other one is GET https://api.api-ninjas.com/v1/&lt;name&gt; with the parameters on its api-ninjas.com/api/&lt;name&gt; page.
