## Setup

| Variable | | What it is |
|---|---|---|
| `TWITTERSCORE_API_KEY` | required | A TwitterScore API key, sent as the api_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The docs give each call only as a URL with a query string (no method is stated); they are plain GETs.
- Any call that takes an account accepts either username or twitter_id.
- Request limits depend on the subscription plan; twitterscore.limits reports what is left.
