## Setup

| Variable | | What it is |
|---|---|---|
| `TIKTOK_ACCESS_TOKEN` | required | A TikTok user access token from the Login Kit OAuth flow with scopes user.info.basic and video.list (TikTok for Developers &gt; your app) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account data only: every call reads the user who authorized the token, never other creators.
- A user access token lives 2 hours; its refresh token lives 180 days and is replaced at each refresh. Refresh outside this catalog and set the new token.
- Fields are opt-in: name the ones you want in the fields query parameter; each needs its scope.
