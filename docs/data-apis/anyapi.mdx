## Setup

| Variable | | What it is |
|---|---|---|
| `ANYAPI_API_KEY` | required | An AnyAPI key, billed from your USD wallet (getanyapi.com dashboard) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Each operation is POST /v1/run/&#123;sku&#125; with a normalized JSON body; the catalog has hundreds of operations, this file names the social and search ones. GET /v1/apis/&#123;sku&#125; returns any operation's input schema and price.
- Every call is billed in USD from the wallet, a flat price per request (listed per endpoint). Reading the balance is free.
- Pagination: send the nextCursor of the previous response as cursor.
- Routing options (source, allowFallbacks, ignoreSources, preferLatencyUnderMs, requireFields) exist on every run call and are not listed here; the defaults pick the cheapest source.
