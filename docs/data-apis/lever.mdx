## Setup

| Variable | | What it is |
|---|---|---|
| `LEVER_POSTINGS_HOST` | optional | api.eu.lever.co for companies whose Lever account is hosted in the EU; a site on the wrong host returns not found. Default `api.lever.co`. One of `api.lever.co`, `api.eu.lever.co`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keyless for reading published postings. Applying to a posting (POST with an API key, rate limited to 2 per second) is not in this entry.
- Each call is scoped to one company's site; there is no cross-company search.
- Filter values (location, commitment, team, department) are case-sensitive and must match the posting exactly.
