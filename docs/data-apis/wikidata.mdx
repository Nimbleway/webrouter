## Setup

| Variable | | What it is |
|---|---|---|
| `WIKIDATA_USER_AGENT` | optional | A descriptive User-Agent with contact details, e.g. 'MyAgent/1.0 (you@example.com)'; Wikimedia blocks clients without one, so set your own for regular use. Default `WebRouter (+https://github.com/Nimbleway/webrouter)`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keyless for reads. Wikimedia's User-Agent policy applies to both hosts: a generic or missing User-Agent can be blocked; set WIKIDATA_USER_AGENT with your contact details.
- Ids: items are Q-numbers (Q42), properties P-numbers (P31 instance of, P569 date of birth). Find ids with the search calls, then read the item.
- The REST API is versioned in the path (wikibase/v1); its rate limits follow MediaWiki's and are not published as numbers.
- SPARQL: 60 seconds of query time per 60 seconds per client (User-Agent plus IP), 5 parallel queries per IP, 30 failing queries per minute, and each query is cut off at 60 seconds. 429 carries Retry-After; ignoring it can get a temporary ban.
