## Setup

| Variable | | What it is |
|---|---|---|
| `IPDATA_API_KEY` | required | An ipdata API key (ipdata.co dashboard). Sent as the api-key query parameter. |
| `IPDATA_API_HOST` | optional | API host: the default, or eu-api.ipdata.co to keep requests on EU servers only. Default `api.ipdata.co`. One of `api.ipdata.co`, `eu-api.ipdata.co`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- A free key allows 1,500 requests a day, with commercial use restricted; quotas reset at 00:00 UTC. Past the free quota requests are blocked.
- Private and reserved addresses return 400 with a message, not a result.
- Bulk lookup (POST /bulk with a JSON array of up to 100 IPs, paid plans only, one credit per IP) is not in this entry.
