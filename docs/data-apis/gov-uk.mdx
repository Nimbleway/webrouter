## Notes

- Free and keyless; no onboarding or agreement.
- Content API: at most 10 requests per second per client; above that requests queue and may time out.
- The Content API covers HTML pages on www.gov.uk only (not other gov.uk subdomains, not attachments or images, not dynamic pages such as search results) and is marked beta.
- Responses are JSON.

<Note>
- Unknown parameters or invalid values return HTTP 422.
- Any field can be filtered with filter_&lt;field&gt; or excluded with reject_&lt;field&gt;; filter_any_/filter_all_ variants exist for multivalued fields. Only the common ones are named here; others need a raw call.
- A start past the end returns no results and no error.
</Note>
