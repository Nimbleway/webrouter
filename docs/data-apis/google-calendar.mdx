## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_CALENDAR_CLIENT_ID` | required | the OAuth client id of a Google Cloud OAuth app with the Google Calendar API enabled (Google Cloud console &gt; APIs & Services &gt; Credentials) |
| `GOOGLE_CALENDAR_CLIENT_SECRET` | required | that OAuth app's client secret |
| `GOOGLE_CALENDAR_REFRESH_TOKEN` | required | a refresh token minted with that OAuth app for the https://www.googleapis.com/auth/calendar.readonly scope |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: reads the calendars of the Google user who granted the refresh token. 'primary' names that user's main calendar.
- Times are RFC3339 with an offset (2026-11-09T09:00:00-05:00 or ...Z). All-day events use start.date/end.date instead of dateTime, and end is exclusive.
- Lists page with pageToken/nextPageToken; a nextSyncToken on the last page lets a later call fetch only changes.
