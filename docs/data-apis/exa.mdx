## Notes

- Auth is the x-api-key header; 'Authorization: Bearer &lt;key&gt;' also works.
- Websets endpoints live under /v0/; a Webset is built asynchronously, so poll it until idle before reading its items.
- Exa search, contents, answers and Agent runs go through web-router's search, extract, answer and research, not this entry.
