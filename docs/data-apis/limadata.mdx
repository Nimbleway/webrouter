|---|---|---|

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Limadata's full API reference (api.limadata.com/docs/basic_v2) sits behind a login, so this entry lists only the endpoints and parameters shown on the public product pages. Others exist (enrich person, search companies, search employees, phone, email verify, web search, extract) but their bodies are not public.
- Credit-priced; every response has an x-credits-cost header. Most find endpoints charge only on a match, and 400, 402 and 429 answers are free.
- Default rate limit is 1 request per second per account across all keys; some enrich and find endpoints are exempt.
