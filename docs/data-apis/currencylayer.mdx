## Setup

| Variable | | What it is |
|---|---|---|
| `CURRENCYLAYER_API_KEY` | required | A currencylayer API access key (account dashboard). Sent as the access_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The default source currency is USD; switching it needs the Basic plan or higher.
- Errors come back as JSON with success false and an error object (code, type, info); check success, not only the HTTP status.
- Plan gates: convert Basic+, timeframe Enterprise+, change Enterprise+, spread Enterprise+.
