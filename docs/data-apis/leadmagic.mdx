## Setup

| Variable | | What it is |
|---|---|---|
| `LEADMAGIC_API_KEY` | required | A LeadMagic API key (app.leadmagic.io &gt; settings). Sent in the X-API-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- You pay only for hits: email find 1, profile-to-email 5, personal email 2, mobile 5, profile search 1, company search 1, validation 0.25 for valid or invalid. Misses, 400 and 429 responses are free.
- Finder endpoints share one rolling 60-second rate allowance per organization; wait for Retry-After on a 429.
- Every lookup is a POST with a JSON body.
- The v3 people search and the analytics endpoints are not in this entry.
