## Setup

| Variable | | What it is |
|---|---|---|
| `MAXMIND_ACCOUNT_ID` | required | Your MaxMind account ID (maxmind.com account portal); the HTTP Basic username. |
| `MAXMIND_LICENSE_KEY` | required | A MaxMind license key (account portal &gt; Manage License Keys); the HTTP Basic password. A GeoLite account's key works on the geolite endpoints only. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- GeoIP2 calls spend prepaid service credits (402 INSUFFICIENT_FUNDS when they run out); the response's maxmind.queries_remaining shows the approximate balance. GeoLite calls are free with a daily query limit, and the same 402 means that limit is reached.
- Use 'me' as the IP to look up the caller's own address. Reserved or private addresses return 400 IP_ADDRESS_RESERVED; an address not in the data returns 404.
- Many error responses in a row can get the account rate-limited (429).
