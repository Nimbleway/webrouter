## Setup

| Variable | | What it is |
|---|---|---|
| `AWR_API_TOKEN` | required | the Developer API token (Settings &gt; Integrations & Exports &gt; Developer API); yearly plans, or monthly from Agency up |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call is one GET to a single script, with the operation named by action; each endpoint here fixes its action.
- Own-account API: it reads projects you already track; it does not look up arbitrary keywords.
- Default limit: 2,000 calls per hour for most operations; exports 150 per hour.
- Project-management answers are JSON with response_code (0 is OK) and message; keyword and market share calls answer CSV.
