## Setup

| Variable | | What it is |
|---|---|---|
| `ALIENVAULT_OTX_API_KEY` | required | An OTX API key (shown on otx.alienvault.com/api once signed in to a free account), sent in the X-OTX-API-KEY header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Indicator calls return one section at a time: ask for general first, which also lists the sections that hold data for that indicator.
- List calls page with limit and page.
- File and URL submission, pulse creation and editing, and subscribe or follow actions (some of them GETs) are not in this entry. URL indicators are left out because the docs show the raw URL inside the path.
