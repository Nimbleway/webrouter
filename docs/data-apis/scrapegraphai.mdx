## Setup

| Variable | | What it is |
|---|---|---|
| `SGAI_API_KEY` | required | a ScrapeGraphAI API key, starting sgai- (scrapegraphai.com/dashboard) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Auth is the SGAI-APIKEY header. All paths are under /api. This is the v2 API; the v1 host and its smartscraper/searchscraper/markdownify/smartcrawler endpoints are deprecated.
- An optional SGAI-Session-Id header groups related requests for the history list.
- Crawls are asynchronous: start, poll status, then page through crawl.pages.
- Monitors (scheduled change detection) are not in this entry.
