## Setup

| Variable | | What it is |
|---|---|---|
| `INTERNETDATA_API_KEY` | some calls | an InternetData API key (internetdata.io console &gt; API keys). Optional: without one the free Unlimited plan answers |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- No key is needed: the free Unlimited plan answers every lookup with country-level location, ASN, company, abuse email, hostname and the Tor, relay, bot, anycast, carrier and satellite flags (terms: https://internetdata.io/terms#no-key).
- A field missing from an answer is one the plan does not include; city, region, coordinates, VPN, proxy and hosting detection need a paid plan.
- Private and reserved addresses answer 200 with is_bogon true, not an error. A 429 carries Retry-After.
