## Notes

- Keyless open data under the Norwegian licence for public data (NLOD).
- An organisation number (organisasjonsnummer) is 9 digits. An enhet is a legal entity; an underenhet is one of its establishments (business locations).
- Paging is page (0-based) and size, default 20; (page+1)*size may not exceed 10,000 or the call is a 400. For the full register use the nightly bulk downloads instead, which this entry does not list.
- Parameter and field names are Norwegian. List filters take comma-separated values.
