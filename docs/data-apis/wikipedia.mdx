## Setup

| Variable | | What it is |
|---|---|---|
| `WIKIPEDIA_LANGUAGE` | optional | Which language edition to call (the subdomain). Default `en`. One of `en`, `de`, `fr`, `es`, `it`, `ja`, `ru`, `pt`, `zh`, `pl`, `nl`, `ar`, `sv`, `uk`, `fa`, `he`, `ko`, `id`, `tr`, `vi`, `cs`, `fi`, `no`, `hu`, `ro`, `simple`. |
| `WIKIPEDIA_USER_AGENT` | optional | A descriptive User-Agent with contact details, e.g. 'MyAgent/1.0 (you@example.com)'; clients without one may be IP-blocked; the default names WebRouter, so set your own with contact details for heavy use. Default `WebRouter (+https://github.com/Nimbleway/webrouter)`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keyless, but Wikimedia requires an informative User-Agent with contact information; set WIKIPEDIA_USER_AGENT.
- No fixed read limit: send requests one at a time, batch titles with | where a call accepts several, and back off on a ratelimited error.
- Action API calls (/w/api.php) need action and format=json; the REST calls (/w/rest.php/v1) answer JSON already.
