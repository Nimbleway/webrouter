## Setup

| Variable | | What it is |
|---|---|---|
| `REVERSECONTACT_API_KEY` | required | A Reverse Contact API key (rc_..., developer dashboard). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Most calls are POST with a JSON body but only read. 100 requests a minute per workspace on Go, Plus and Max, which also cap profiles per day; a 429 is free and says when to retry.
- Email, phone and verification calls are asynchronous; poll reverse-contact.task.get instead of passing a callback URL.
- Live profile fetches, prompt and lookalike search, bulk tasks and Lists are not in this entry.
