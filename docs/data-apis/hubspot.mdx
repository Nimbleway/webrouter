## Setup

| Variable | | What it is |
|---|---|---|
| `HUBSPOT_ACCESS_TOKEN` | required | a HubSpot private app or service key access token with the crm.objects.*.read scopes needed |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Records return only default properties unless 'properties' names the ones wanted; list the available ones with hubspot.properties.list.
- Paging is a cursor: send paging.next.after from the previous answer as 'after'. No paging.next means the last page.
- Deal stages and pipelines come back as internal ids (e.g. dealstage 'appointmentscheduled'); map them to labels with hubspot.pipelines.list.
- Search is limited to 5 requests per second per account and 10,000 results per query; newly changed records take a few moments to appear in search.

</CodeGroup>

<Note>
- A read over POST.
- Archived records never appear. IN/NOT_IN values on string properties must be lowercase; enumeration properties match case-sensitively.
- The request body may be at most 3,000 characters; paging past 10,000 results answers 400.
</Note>
