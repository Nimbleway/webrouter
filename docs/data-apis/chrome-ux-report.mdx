## Setup

| Variable | | What it is |
|---|---|---|
| `CRUX_API_KEY` | required | a Google Cloud API key from a project with the Chrome UX Report API enabled (Google Cloud console &gt; APIs & Services &gt; Credentials); the API is free |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Both calls are POSTs that only read data.
- Pass origin or url, never both. Only origins and URLs with enough Chrome traffic have a record; others have none.
- Units follow the metric: LCP, INP, FCP and TTFB in milliseconds; CLS is unitless and its p75 comes back as a string ('0.05').
- Quota: 150 queries per minute per Google Cloud project, shared by both calls, free and not raisable.
- Every record is a 28-day rolling window ending about two days before the update; dates are Pacific Standard Time.
