## Setup

| Variable | | What it is |
|---|---|---|
| `IPREGISTRY_API_KEY` | required | An Ipregistry API key (Ipregistry dashboard). Sent in the Authorization header as 'ApiKey &lt;key&gt;'. |
| `IPREGISTRY_API_HOST` | optional | API host: the default, eu.api.ipregistry.co to keep requests on EU nodes, or gb.api.ipregistry.co for UK nodes only. Default `api.ipregistry.co`. One of `api.ipregistry.co`, `eu.api.ipregistry.co`, `gb.api.ipregistry.co`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billing is in credits: 1 per single lookup; a batch costs one per value plus one per request (3 addresses cost 4).
- Every endpoint takes fields to trim the response: comma-separated, dot syntax for nested fields (security.is_tor), a leading minus to exclude.
- Batch lookups by POSTing a JSON array are not in this entry; comma-separated values in the path do the same over GET.
