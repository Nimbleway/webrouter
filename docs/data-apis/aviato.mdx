## Setup

| Variable | | What it is |
|---|---|---|
| `AVIATO_API_KEY` | required | an Aviato API key (data.aviato.co dashboard &gt; Teams &gt; API Keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credit-based; billing.balance shows the team balance. Previews and 404s cost nothing; most enrich calls cost a credit per successful lookup.
- Company endpoints accept any one identifier (id, website, linkedinURL, crunchbaseID...). List endpoints need perPage and page.
- Search endpoints take the Aviato DSL; person.simple_search is the flat-parameter alternative. At most 15 searches run concurrently.
