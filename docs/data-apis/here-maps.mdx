## Setup

| Variable | | What it is |
|---|---|---|
| `HERE_API_KEY` | required | A HERE API key (platform.here.com &gt; Access manager &gt; Apps &gt; API keys), sent as the apiKey query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Each service has its own host; this entry routes each call to the right one.
- Points are latitude first (at=52.5308,13.3856; origin=52.5308,13.3856), but a bbox is west longitude, south latitude, east longitude, north latitude.
- Search areas: in=countryCode:USA,CAN (ISO alpha-3, uppercase), in=circle:52.53,13.38;r=10000 (metres) or in=bbox:13.08,52.33,13.76,52.67.
- Parameters marked RESTRICTED or ALPHA in HERE's reference need a contract or may change; they are left out here.
