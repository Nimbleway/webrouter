## Setup

| Variable | | What it is |
|---|---|---|
| `ANYMAILFINDER_API_KEY` | required | Anymail Finder API key (account API page; click Enable API if hidden). Sent raw, with no Bearer prefix. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- You are charged only when a valid email is returned; not found, blacklisted and (since 2026-10-05) risky results are free. Repeat searches within 30 days are free.
- Searches wait for the answer.
- Bulk and GeoLead jobs are not included here beyond status; credits are charged on first download of results.
