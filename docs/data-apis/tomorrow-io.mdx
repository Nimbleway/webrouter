## Setup

| Variable | | What it is |
|---|---|---|
| `TOMORROW_IO_API_KEY` | required | A Tomorrow.io API key (app.tomorrow.io &gt; Development &gt; API keys), sent as the apikey query parameter. Keys carry full account privileges. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- location takes 'latitude, longitude' (latitude first, e.g. 42.3478, -71.0466), a city name, a US zip with country (10001 US) or a UK postcode.
- Requests per second, hour and day are capped by plan; over the cap answers 429. Remaining-quota headers are sent to Enterprise accounts only.
- units is metric (default) or imperial; field meanings and units are in the Weather Data Layers reference.
