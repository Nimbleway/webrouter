## Setup

| Variable | | What it is |
|---|---|---|
| `LISTENNOTES_API_KEY` | required | a Listen API key (listennotes.com/api/dashboard). Sent in the X-ListenAPI-Key header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The FREE plan has a monthly request quota (X-ListenAPI-FreeQuota header) and answers 429 once it is used up; it also caps search at the first 30 results (offset &lt; 30) and returns low-resolution images.
- Timestamps (published_after, published_before, pub_date_ms) are Unix milliseconds; audio lengths are minutes.
- Flags such as safe_mode and sort_by_date are 0 or 1, not booleans.
- A mock server at https://listen-api-test.listennotes.com/api/v2 answers with fake data and no key.
- Playlists, podcast submission, RSS refresh and deletion requests are in the API but not in this entry.
