## Setup

| Variable | | What it is |
|---|---|---|
| `FMCSA_API_KEY` | required | A QCMobile WebKey: sign in at mobile.fmcsa.dot.gov/QCDevsite with Login.gov, then My WebKeys &gt; Get a new WebKey. Sent as the webKey query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Look a carrier up by name or docket number first to get its DOT number, then use the per-carrier endpoints.
- A name search returns at most 50 carriers per call; page with start and size.
