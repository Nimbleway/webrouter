## Setup

| Variable | | What it is |
|---|---|---|
| `META_AD_LIBRARY_ACCESS_TOKEN` | required | a Meta access token for an app whose developer has been identity-verified for the Ad Library API (https://www.facebook.com/ID) |
| `META_AD_LIBRARY_API_VERSION` | optional | Graph API version used for ads_archive. Default `v27.0`. One of `v25.0`, `v26.0`, `v27.0`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Public data, not your own account: any ad in the library, subject to Meta's coverage.
- Ads outside the EU are only returned when they concern social issues, elections or politics; commercial ads are searchable for the EU and UK.
- Keywords are not translated: write search_terms in the ads' language.
- Error 190 is an invalid token, 613 a rate limit.
