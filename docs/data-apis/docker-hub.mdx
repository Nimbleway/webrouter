## Setup

| Variable | | What it is |
|---|---|---|
| `DOCKER_HUB_TOKEN` | some calls | a short-lived bearer JWT from POST https://hub.docker.com/v2/auth/token with your username and a personal access token; needed for private repositories and endpoints the docs mark as authenticated |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Public repositories are readable without a token. The bearer token is a JWT minted from POST /v2/auth/token (&#123;identifier, secret&#125;); it expires, so refresh DOCKER_HUB_TOKEN when calls start returning 401.
- Rate-limited: a 429 carries Retry-After (seconds). These limits are separate from image pull limits.
- Lists page with page and page_size and return count, next and previous.
