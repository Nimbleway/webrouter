## Setup

| Variable | | What it is |
|---|---|---|
| `OANDA_API_KEY` | required | An OANDA personal access token (fxTrade Account Management Portal &gt; Manage API Access). Sent as an Authorization Bearer header. |
| `OANDA_HOST` | optional | api-fxpractice.oanda.com for a practice (demo) account token, api-fxtrade.oanda.com for a live account token. Use the host that matches the account the token belongs to. Default `api-fxpractice.oanda.com`. One of `api-fxpractice.oanda.com`, `api-fxtrade.oanda.com`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Needs an OANDA fxTrade account, practice or live; every data call is scoped to an account ID.
- Limit: 120 requests per second per IP, and at most 2 new connections per second; over it returns 429.
- Instruments are written BASE_QUOTE with an underscore: EUR_USD, XAU_USD.
- Times come back RFC 3339 by default; an Accept-Datetime-Format: UNIX header switches them to Unix seconds.
- Only market-data reads are listed; the order, trade and transfer endpoints are left out on purpose.
