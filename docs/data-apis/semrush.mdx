## Setup

| Variable | | What it is |
|---|---|---|
| `SEMRUSH_API_KEY` | required | a Semrush API key (Subscription info &gt; API units in your Semrush account); it spends your API unit balance |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every report is a GET with a type parameter naming the report; each endpoint here fixes it, and you must still send it (the enum has one value).
- Reports answer CSV (semicolon-separated, header row), not JSON. Use export_columns to choose columns.
- Billing is in API units per returned line, so always set display_limit; the default is up to 10,000 lines.
- Backlink reports live under /analytics/v1/ instead of the root path; the unit balance check is on a separate http host and is not included.
