## Setup

| Variable | | What it is |
|---|---|---|
| `ADYNTEL_API_KEY` | required | your Adyntel API key (adyntel.com profile &gt; Integrations) |
| `ADYNTEL_EMAIL` | required | the email of your Adyntel account; sent with every call |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every endpoint is a POST, and the API key and account email go in the JSON body beside the call's own fields, as Adyntel's examples show; the router adds both.
- Credits: roughly one per page (about 30 ads); a 204 (no ads found) is not charged. 401 means bad credentials, 402 not enough credits.
- Pagination (all but meta.keyword_search): send the previous answer's continuation_token back with the same other fields. The last page returns a null token.
- all_ads and webhook_url are left out of this catalog: they push results to another URL and can burn many credits.
