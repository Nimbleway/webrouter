## Setup

| Variable | | What it is |
|---|---|---|
| `BRIGHTDATA_API_TOKEN` | required | a Bright Data API key (control panel &gt; Account settings &gt; API keys) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Auth is 'Authorization: Bearer &lt;API key&gt;'.
- Filtering a dataset starts a billed snapshot job; poll its status, then download it.
- Bright Data scrapers, Web Unlocker and SERP go through web-router's extract, search and live_data, not this entry.
