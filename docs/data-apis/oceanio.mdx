|---|---|---|
| `OCEAN_API_TOKEN` | required | an Ocean.io API token (app.ocean.io, API settings) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credit-priced per result: searches 0.2, enrich 0.1, bulk lookup 0.05, autocomplete 0.1 per call. Email reveal (1 credit) and phone reveal (10) are asynchronous and deliver to a webhook, so they are not listed.
- Paging uses searchAfter: send the value from the previous response.
- Search 'preview' endpoints exist only on enterprise or older plans (402 otherwise).
- The docs also accept the token as an apiToken query parameter; sending both a header and a query token is an error.
