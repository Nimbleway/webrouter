## Setup

| Variable | | What it is |
|---|---|---|
| `META_ADS_ACCESS_TOKEN` | required | a long-lived access token with the ads_read permission (a system-user token from Meta Business Settings &gt; System users, or a user token from a Meta app) |
| `META_GRAPH_API_VERSION` | optional | Graph API version. Meta retires old versions after about two years; pin one only to stay on it deliberately. Default `v25.0`. One of `v25.0`, `v26.0`, `v27.0`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: reaches ad accounts the token's user or system user was given access to.
- Ad account ids carry the act_ prefix in paths. Insights money fields (spend) come back as strings in the account currency, not cents.
- Pagination is cursor style: the answer's paging.next URL, or paging.cursors.after passed back as after.
- This catalog covers reads only; creating or changing campaigns is not included.
