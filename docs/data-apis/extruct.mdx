## Setup

| Variable | | What it is |
|---|---|---|
| `EXTRUCT_API_TOKEN` | required | An Extruct API token (app.extruct.ai/api-tokens), sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Search and lookalike return at most 250 results a call; page with pagination.offset. Paid plans reach 2,000 results per query, the free tier 25.
- Deep Search and Deep Research are async: create the task, poll GET by id until status is done (or is_exhausted for Deep Search), then read results.
- Company lookup costs 0 credits; Deep Research bills 2 credits per research agent that runs and reserves the depth's full budget at start.
- Table (enrichment) endpoints are not in this entry.
