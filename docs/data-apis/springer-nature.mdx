## Setup

| Variable | | What it is |
|---|---|---|
| `SPRINGER_NATURE_API_KEY` | required | API key from the API Management page of a dev.springernature.com account; sent as the api_key query parameter. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Basic (free) plan: 100 requests a minute and 500 a day per API; Premium raises it (Meta and Metadata 300/min, 10,000/day).
- Page with s (start, from 1) and p (page size, default 10). Max p: Meta API 25 on Basic, 100 on Premium; Open Access API 20.
- Which query constraints work depends on the plan; Premium-only filters fail on a Basic key.
