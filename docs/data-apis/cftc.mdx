## Setup

| Variable | | What it is |
|---|---|---|
| `CFTC_API_KEY` | some calls | optional Socrata application token for publicreporting.cftc.gov; without one, calls share a per-IP pool and may get 429s. Sent in the X-App-Token header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Free and keyless. The portal is a Socrata site: each dataset is queried with SoQL parameters (&#36;where, &#36;select, &#36;order, &#36;limit, &#36;offset, &#36;q).
- Common columns: report_date_as_yyyy_mm_dd (the as-of date of the positions), market_and_exchange_names, contract_market_name, cftc_contract_market_code, commodity_name, open_interest_all; the position columns differ by report.
- Values come back as JSON strings, numbers included.
- Default &#36;limit is 1,000 rows; add an &#36;order when paging with &#36;offset.
- Each report family has a futures-only and a futures-and-options-combined dataset; pick the dataset id in the path.
