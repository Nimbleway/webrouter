| Variable | | What it is |
|---|---|---|
| `SECURITYTRAILS_API_KEY` | required | A SecurityTrails API key (SecurityTrails control panel &gt; API), sent in the APIKEY header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every call counts against the plan's monthly query allowance: account.usage shows what is left.
- The API is read-only, per SecurityTrails; search is a POST with a JSON body.
- Feeds, the DSL search, scrolling and the Attack Surface Intelligence API are not in this entry.
