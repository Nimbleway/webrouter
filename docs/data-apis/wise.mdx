## Setup

| Variable | | What it is |
|---|---|---|
| `WISE_API_KEY` | required | A Wise API token: a personal API token (business account settings &gt; Developer tools &gt; API tokens) or a user access token. Sent as an Authorization Bearer header. |
| `WISE_HOST` | optional | api.wise.com for live accounts, api.wise-sandbox.com for the sandbox. Use the host the token was issued for. Default `api.wise.com`. One of `api.wise.com`, `api.wise-sandbox.com`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Reads only. Quotes, transfers, conversions, balance movements and every other call that moves money are left out on purpose.
- Every endpoint here is documented as accepting both user tokens and personal API tokens, though Wise describes personal tokens mainly for the payouts workflow.
- Balance statements are left out: outside the US, CA, AU, NZ, SG and MY they need strong customer authentication, and personal tokens cannot read them.
- The API is versioned by quarter in the base path (2026Q4).
