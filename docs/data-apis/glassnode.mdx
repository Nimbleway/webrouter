## Setup

| Variable | | What it is |
|---|---|---|
| `GLASSNODE_API_KEY` | required | A Glassnode API key (Studio &gt; Settings &gt; API). Sent in the X-Api-Key header; an api_key query parameter also works. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The full API needs a Professional subscription. Advanced subscribers get the Light API: 14 days of history, 24h resolution only, 50 calls a day.
- Each data call costs data credits: 1 for BTC, 2 for any other asset. Metadata calls cost none.
- Default limit is 600 requests/minute (x-rate-limit-* response headers); over it returns 429.
- Series come back as [&#123;t, v&#125;] with t in Unix seconds; multi-value metrics put an object in o instead of a number in v.
- Hundreds of metrics share one shape, GET /v1/metrics/&lt;group&gt;/&lt;metric&gt; with a, s, u, i; list them with metadata.metrics and check a metric's parameters with metadata.metric.
