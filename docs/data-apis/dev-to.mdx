## Setup

| Variable | | What it is |
|---|---|---|
| `DEV_TO_API_KEY` | some calls | Optional DEV API key, generated at dev.to/settings/extensions under 'DEV API Keys'; sent in the api-key header. Public reads work without it. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- The public endpoints listed here need no key; a key is needed for writes and for the authenticated user's own data, which are not listed.
- Paging is page (from 1) and per_page (1 to 1000; default 30, tags default 10).
- Dates and date-times are RFC 3339.
