## Setup

| Variable | | What it is |
|---|---|---|
| `GOOGLE_MAPS_API_KEY` | required | a Google Maps Platform API key from a Cloud project with billing and the Places API (New), Geocoding API and Street View Static API enabled (Google Cloud console &gt; Google Maps Platform &gt; Keys & Credentials) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Billed per request by SKU, on a Cloud project with billing enabled; Places calls are billed by the most expensive field in the mask, so keep field masks short.
- Places (New) calls need a field mask (the fields parameter); without one they fail.
- Geocoding and Street View metadata answer HTTP 200 with a status field; read it.
