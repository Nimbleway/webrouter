## Setup

| Variable | | What it is |
|---|---|---|
| `IPINFO_TOKEN` | required | an IPinfo access token (ipinfo.io account &gt; Token); free accounts get unlimited Lite lookups |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Lite (/lite) is free and unlimited: country, continent and ASN only. Core (/lookup) needs a paid plan and returns city-level geo plus network flags.
- Paid plans have a monthly request quota; past it calls return 429 unless metered billing is on. No per-second throttling.
- Use 'me' as the IP to look up the caller's own address.
