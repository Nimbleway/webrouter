## Setup

| Variable | | What it is |
|---|---|---|
| `TELNYX_API_KEY` | required | A Telnyx API key (KEY...) from the Mission Control portal, sent as a Bearer token. |
| `TELNYX_API_HOST` | optional | Regional endpoint: api.telnyx.com (North America, default), .eu, .com.au, .ca or .me. The same key works on every region. Default `api.telnyx.com`. One of `api.telnyx.com`, `api.telnyx.eu`, `api.telnyx.com.au`, `api.telnyx.ca`, `api.telnyx.me`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Lists page with page[number] and page[size]; filters use bracketed names (filter[status]).
- Phone numbers are +E.164 everywhere.
- Rate limits vary by endpoint and are counted per region; a 429 means slow down, and x-ratelimit-remaining is sent when available.
