## Setup

| Variable | | What it is |
|---|---|---|
| `ATTOM_API_KEY` | required | An ATTOM API key (api.developer.attomdata.com, free trial available), sent in the apikey header. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Only answers with HTTP 200 count against the plan's monthly allowance. Beyond the HTTP code, the body's status element carries ATTOM's own status code (for example when no property matched).
- Address calls take the street in address1 and 'City, ST' (or the ZIP) in address2. Calls keyed by attomid take the id returned by an address call.
- Many more filters (beds, size, dates, value ranges, geoIdV4 areas) are listed in ATTOM's Search Filters section; only the parameters in its interactive reference are listed here.
