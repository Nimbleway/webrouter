## Setup

| Variable | | What it is |
|---|---|---|
| `ALBACROSS_API_KEY` | required | An Albacross secret API key (dashboard &gt; Settings &gt; API Keys). Sent as Authorization: Api-Key &lt;key&gt;. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- No match is a 204 with no body, not a 404; a malformed IP or domain is a 400.
- Usage is rate-limited per key (429 when exceeded); limits are not published in the docs.
- Use the secret key server-side; the public key is for the browser Reveal script with domain whitelisting.
