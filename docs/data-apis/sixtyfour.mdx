| Variable | | What it is |
|---|---|---|
| `SIXTYFOUR_API_KEY` | required | a Sixtyfour API key starting api_ (app dashboard, Get an API Key) |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Credit-priced; see the notes per call and the Credit Costs page. Each key belongs to one team and counts toward its monthly spend limit.
- Long research runs are async: the -async endpoints return a task_id, poll GET /job-status/&#123;task_id&#125;. Bulk and Atlas investigation endpoints exist but are not listed.
- The lead and struct fields are free-form objects: struct maps each field you want to a description of it.
