## Notes

- Keyless, run by the Slovak Ministry of Justice. An OData API: query options are &#36;filter, &#36;skip and &#36;expand, and lists come back as &#123;"@odata.context", "value": [...]&#125;.
- Property names in filters are PascalCase as in responses (Ico, ObchodneMeno, CisloVlozky, Priezvisko); strings take single quotes.
- Each list also has a /&#36;count form that returns the number of matching records. Field names and values are in Slovak.
