## Setup

| Variable | | What it is |
|---|---|---|
| `CLORO_API_KEY` | required | a cloro API key (dashboard.cloro.dev/api-keys); one key grants every endpoint |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- cloro runs real browser sessions against each AI engine, so calls take longer than a normal API; use the async endpoints for volume.
- Credits per call: ChatGPT 5, Gemini 4, Perplexity 4, AI Mode 4, Bing AI Mode 4, Google Search 3, Google News 3, product panel 1; sync /v1/monitor/* calls add +2 on top, async calls do not. Read X-Credits-Charged on a sync answer for the exact charge.
- Answers are wrapped as &#123;success, result&#125;; result holds the text, sources and provider-specific blocks.
- Country is required on most endpoints and there is no default. List supported codes with cloro.meta.countries.
