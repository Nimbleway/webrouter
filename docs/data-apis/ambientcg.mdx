## Setup

| Variable | | What it is |
|---|---|---|
| `AMBIENTCG_API_KEY` | some calls | Optional API token shown at ambientCG.com/activate to Patreon supporters; it unlocks their tier's benefits (early access, exclusive files). |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Keyless for the public CC0 library; a token only adds Patreon benefits.
- Read-only: every v3 call is a GET.
- Run by one person: the operator warns it may be less reliable than an enterprise API, so cache results.
