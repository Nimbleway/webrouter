## Setup

| Variable | | What it is |
|---|---|---|
| `BING_WEBMASTER_API_KEY` | required | a Bing Webmaster Tools API key (Settings &gt; API Access &gt; Generate API Key); one key per user, valid for all of that user's verified sites |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Own-account API: only sites added and verified in the key owner's Bing Webmaster Tools.
- Answers wrap the result in a 'd' field; dates come as '/Date(1316156400000-0700)/' (milliseconds since 1970 plus a UTC offset).
- Errors answer HTTP 400 with &#123;ErrorCode, Message&#125;, e.g. ErrorCode 3 InvalidApiKey.
- Search performance data is updated weekly.
