## Setup

| Variable | | What it is |
|---|---|---|
| `SENTRY_AUTH_TOKEN` | required | A Sentry auth token: an organization token, a user token, or an internal integration's token, with the read scopes the calls need (org:read, project:read, event:read). |
| `SENTRY_API_HOST` | optional | sentry.io, or the organization's data region: us.sentry.io or de.sentry.io. Self-hosted Sentry is not covered. Default `sentry.io`. One of `sentry.io`, `us.sentry.io`, `de.sentry.io`. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Every path takes the organization slug; paths end with a slash.
- Paging is by the Link response header: follow the rel="next" cursor while it says results="true". A next cursor is always present, even on the last page.
- Rate limits are per endpoint and per caller; a 429 means wait, and X-Sentry-Rate-Limit-* headers report the window.
- Issue lists default to query=is:unresolved; send an empty query for every issue.
