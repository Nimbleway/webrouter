## Setup

| Variable | | What it is |
|---|---|---|
| `SNITCHER_API_TOKEN` | required | A Snitcher personal access token (app.snitcher.com &gt; Settings &gt; Account &gt; API). Sent as a Bearer token. |

Put them in your environment or `.env`; [Data APIs](/vendors) covers the other ways.

## Notes

- Reads your own workspaces only: companies are those identified on sites running the Snitcher tracker. There is no server-side lookup of an arbitrary IP; the real-time Spotter identification runs in the browser on authorised domains.
- Rate limit: 60 requests a minute per token; 429 says Too Many Attempts.
- Paging: page and size (1-1000); page x size may not exceed 25,000 rows, so narrow by date instead of paging deeper.
- Revealing contact emails or phones, tags, custom fields and workspace settings are writes or spend reveal credits and are not in this entry.
